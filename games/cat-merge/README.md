# 合成小猫 / Kitty Merge

纸箱里的物理合成小游戏：投下小猫，让同级猫咪接触合成更大的猫。采用项目统一的纸张、铅笔线稿和低饱和配色。

## 入口与操作

- 从 `../../games.html` 搜索「合成小猫」进入，入口为 `index.html`。
- 桌面：鼠标移动瞄准，点击投放；也可用左右方向键瞄准、空格投放。
- 触摸：在游戏画布内拖动瞄准，松手投放；下方按钮可在当前瞄准位置投放。
- `P` / `Esc` 或右上角按钮暂停。暂停面板可继续或重新开始。
- 查看说明、切到其他页面或窗口失焦会暂停；回到游戏后主动继续。
- 音效默认关闭，可用右上角按钮开启。音效与最高分设置保存于当前浏览器；存储不可用时仍可游玩。

## 玩法

- 共 10 个等级，颜色、花纹、大小和数字区分等级；投放只出现前 4 级。
- 每局前两只都是 1 级，便于理解合成。后续投放使用加权随机。
- 相同等级接触后变成更大一级。合成后的猫仍参与碰撞，可继续引发连锁。
- 合成基础分为 `10 × 2^等级索引`（索引从 0 开始，首次合成得 20 分）。间隔不超过 1.65 秒的连续合成增加倍率，最高 5 倍。
- 两只 10 级猫合成会离开纸箱，并获得 `4096 × 连锁倍率` 分，可继续刷分。
- 新猫有 1.25 秒越线宽限。已有猫持续超过虚线 2 秒则结束；猫回到线下会清空倒计时。
- 投放间隔 0.46 秒；箱口被占用时需要换个落点，不会把新猫塞进其他猫内部。

## 文件

- `engine.js`：固定 120 Hz 步进、重力、圆形碰撞、迭代约束、合成、计分和危险线判定。
- `art.js`：原生 Canvas 绘制猫咪，不需要图片或网络资源。
- `game.js`：输入、响应式画布、界面状态、反馈、Web Audio 和本地记录。
- `translations.js`：接入全局 `BooplandI18n` 的八国语言文案。
- `cover.svg`：大厅封面；根目录 `gamelist.js` 已登记游戏及七种外语卡片翻译。

保持原生静态 HTML/CSS/JavaScript、相对路径，无构建、CDN、模块加载或 fetch 数据依赖。保留全局返回链接语言与统一统计加载器。
