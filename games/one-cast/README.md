# 一键钓鱼

纸张、铅笔线条和低饱和湖水，一只戴草帽的小猫在木码头边钓鱼。原生 HTML / CSS / JavaScript，场景由 Canvas 绘制，封面为独立 SVG；没有构建步骤、第三方素材或运行依赖。

从项目根目录的 `games.html` 搜索「一键钓鱼」进入，也可直接打开本目录的 `index.html`。所有资源均为相对路径，沿用全站八国语言和统计加载器。

## 操作与玩法

- 点击主按钮或按空格抛竿；等待约 2–5 秒，看到「!」再按一次收杆。抛竿动画期间忽略重复输入。
- 咬钩后 1.9 秒内收杆成功；前 0.48 秒为完美收杆，得分 ×1.5，珍稀和传说鱼的抽取权重翻倍。
- 提前收杆或超时会空竿，连钓归零，但不扣分。没有全局倒计时。
- 1–3 连钓为 ×1，4–6 为 ×1.5，依次增加，13 连钓起封顶 ×3。鱼种基础分为 30–400 分。
- 8 种鱼各有名称、稀有度、配色和重量范围。图鉴记录累计捕获数量和最大重量。
- P / Esc 或顶部暂停键暂停；切到其他标签页、窗口失焦、打开图鉴或说明时暂停。恢复时保留原来的收杆时间；暂停与隐藏页面停止动画循环和音效。
- 音效默认关闭，由用户点击开启；采用浏览器合成音，不加载音频文件。
- 「新的一次出发」只清除本次得分和连钓，保留图鉴和最高分。手机可通过图鉴底部进入此功能。
- 图鉴和最佳手记保存在 `boopland-one-cast-v1`。存储不可用时维持本次访问内的记录；本局得分不跨刷新保存。语言沿用 `BooplandI18n`，不另设切换器。

## 验证

在项目根目录运行：

```sh
node --test games/one-cast/engine.test.cjs
```

10 项测试通过：抛竿防重复、收获计分、提前/超时空竿、完美时机边界、暂停保留计时、卡顿不吞掉反应时间、连钓倍率上限、8 种鱼及重量范围、新的一次出发、损坏存档恢复、八国语言键名及占位符一致性（部分内容合并在同一测试内）。

内置浏览器通过 HTTP 静态预览实测：

- 中文准备界面：320 × 568、360 × 640、390 × 844、568 × 320、844 × 390、768 × 1024、1024 × 768、1280 × 720、1920 × 1080。无页面溢出，主按钮完整可见。
- 八国语言的 320 × 568 与 568 × 320 准备界面：标题不与返回/工具重叠、按钮完整、页面无溢出、返回链接保留语言。
- 抛竿、真实咬钩后收杆、计分与解锁图鉴、提前收杆、空格输入、P 暂停和继续、图鉴弹窗内滚动、重新出发、刷新后保留图鉴及最佳分、音效开关反馈。
- 大厅搜索找到唯一钓鱼卡片、进入游戏和返回大厅；HTTP 页面未发现脚本错误。静态资源、封面和八国语言文案已检查。

验证限制：内置浏览器安全策略不允许 `file://` 导航，因此直接双击运行仅检查相对路径及无模块/网络加载依赖，未直接实测。未使用实体触摸设备或人工听音；超时、完美边界、全部鱼种和高连钓由规则测试覆盖。
