# 纸桥工程师 · Paper Bridge

在方格纸上，用有限的桥面、支撑木条、绳索和预算连接两岸，再让小邮车过桥。参考 Poly Bridge 的搭桥与试车玩法，使用本项目的原创纸张、铅笔线稿和低饱和美术。

入口：`index.html`。已登记到根目录 `gamelist.js` 的「益智」分类。纯原生 HTML / CSS / JavaScript，资源均为相对路径；无需安装、构建、CDN、后端或数据请求。

## 操作

- 选择木桥面、支撑木条或绳索。点两个网格点连接，也可以从起点拖到终点。所有构件只在端点相连，交叉处不自动接合。
- 圆环是固定锚点。小车只在桥面上行驶；木条承受拉力和压力，绳索只承受拉力。三角结构或高处的吊索能稳定桥面。
- 每种材料都有数量、长度与费用限制。预算和剩余数量即时更新。撤销、橡皮擦和清空均退回材料及费用；清空也可以撤销。
- 参考草图展示一种可行方案，所选材料的部分会高亮，可以随时关闭草图自行设计。
- 点击「放小车过桥」试车。绿、黄、红表示逐渐增加的受力；过载会断裂，小车会坠落。可暂停、切换 1× / 2× 速度或随时返回建造，原始设计完整保留。
- 键盘：`1` / `2` / `3` 选择材料，`X` 橡皮擦，方向键移动网格光标，`Enter` 选点连接，`Delete` 删除附近构件，`Esc` 取消连线或暂停，`Ctrl+Z` / `Cmd+Z` 撤销，空格试车或暂停。
- 顶部关卡名称打开选关，全部六关自由尝试；右上角有建桥手册，左上角始终保留返回大厅入口。

| 再远一点点 | 10 米跨度，让桁架连续分担荷载 | 2,050 |

| 河心的小岛 | 12 米跨度，利用河心岛的固定支撑 | 2,450 |

每关三颗星分别奖励：安全到达、无构件断裂、节省至少 15% 预算。六关都有实际可通关的三星设计，第五关参考草图保留了冗余绳索，精简后能获得预算星。

## 实现

- `engine.js`：独立于 DOM 的 120 Hz 固定步长 XPBD 约束模拟。桥面和木条使用双向弹性杆，绳索使用单向拉力约束；包含自重、车辆轮载、阻尼、应力累积、断裂与坠落。车辆沿两处轮下的桥面接触行驶，并把载荷分配到构件端点。
- `scene.js`：Canvas 绘制原创纸河谷、小邮车、桥梁、锚点、构件预览和受力色。按容器完整容纳有效区域，像素比最高为 2，缩放时保留本局状态。
- `game.js`：鼠标 / Pointer Events 触摸 / 键盘输入、设计编辑、暂停、关卡、结算及存储。切换标签或窗口失焦时暂停试车，页面隐藏时停止动画循环。
- `translations.js`：接入根目录 `i18n.js`，完整覆盖中、英、日、韩、法、德、西、巴西葡语；切换语言不重置当前设计。返回大厅保留语言参数。
- 设计、星数和最低通关费用存储在 `boopland-paper-bridge-v1`。读取时验证材料、坐标、数量和预算；存储不可用时可继续当前会话。
- 纸纹与封面为本地 SVG。没有音频、登录或额外统计，只按项目约定引入公共 `analytics.js`。

## 验证

在项目根目录运行：

```sh
node --test games/paper-bridge/engine.test.cjs
```

23 项测试覆盖全部六关的真实物理通关与三星设计、无支撑桥面倒塌、断桥、超载、木条抗压、绳索松弛、固定锚点、不同帧率、暂停、费用退款、长度 / 数量 / 预算限制、重叠与重复构件、异常存档、八国语言和大厅资源登记。

浏览器实测：

- 鼠标两点连接和拖动绘制；第一关木架桥及第三关绳索桥均三星通关。
- 无支撑桥面失败、返回建造保留设计、暂停 / 恢复、2× 试车、下一关、自由选关、刷新后读取设计与星数。
- 键盘建桥、删除退款、清空后撤销恢复；说明弹窗在短屏内滚动。
- 九种布局：`320×568`、`360×640`、`390×844`、`568×320`、`844×390`、`768×1024`、`1024×768`、`1280×720`、`1920×1080`。页面无横向或纵向溢出，主要控件未越界。
- 八种语言在 `320×568` 和 `568×320` 下的布局、按钮文本，以及巴西葡语短横屏的暂停与试车控制。
- 静态 HTTP 访问、大厅搜索、进入游戏及带语言参数返回；浏览器未报告脚本错误。

未实测：真实手机硬件触摸、Safari、`file://` 直接双击。已检查直接打开所需的相对资源路径和普通脚本加载方式；不依赖模块或 `fetch`。
