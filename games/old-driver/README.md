# 我是老司机

纯静态、纸张手绘风格的俯视停车小游戏。入口为 `index.html`，已登记到根目录 `gamelist.js`。无需安装或构建；可从大厅进入，也可直接打开 HTML。

## 玩法

- 八关依次解锁：直线初体验、转角遇见车位、倒车第一课、绕桩小练习、侧方停车、斜着也要正、倒车入库、老司机毕业考。
- `W / ↑` 前进；`S / ↓` 先制动再倒车；`A D / ← →` 转向；空格刹车；`P` 暂停；`R` 重来。
- 触屏按住方向按钮和踏板，可以同时操作；松开、指针取消、失焦都会清除输入。
- 车辆完全进入绿色车位，车头与箭头偏差小于 10°，速度降到阈值以下并保持 1.2 秒，即可过关。倒车关还要求最后一次有效行驶方向为倒车。
- 同一次持续接触只计一次碰撞；离开后再撞才重新计数。5 次碰撞或超时结束本次挑战。
- 三星需要零碰撞、在提示的目标时间内完成、精度至少 70%。用时、碰撞和精度共同影响得分。
- 最佳得分和星数保存在 `boopland-old-driver-v1`；禁用存储时仍可玩，本次页面会话内仍保留解锁进度。
- 音效默认关闭，可通过右上角按钮开启。切换标签页和窗口失焦时暂停。
- 通过全站 `BooplandI18n` 支持八国语言；游戏不另设语言切换入口。

## 文件

- `engine.js`：固定小步长的车辆运动、旋转矩形碰撞、停车判定和关卡定义。
- `game.js`：Canvas 绘制、输入、弹层、评分和本地记录。
- `translations.js`：八国语言的静态与动态文案。
- `style.css`、`cover.svg`：响应式纸张界面与独立手绘封面。

## 验证

运行 `node games/old-driver/engine.test.cjs`，11 项检查涵盖所有关卡的出生点/目标点、完整前进及倒车过关流程、碰撞与脱困、五次碰撞失败、停车方向/边界/停稳时长、暂停/超时、帧率一致性与翻译键覆盖。

浏览器检查覆盖 `320×568`、`360×640`、`390×844`、`568×320`、`844×390`、`768×1024`、`1024×768`、`1280×720`、`1920×1080` 的页面边界与主要控件；对小竖屏、短横屏和桌面做了视觉检查。八国语言均检查了 `320×568` 下的页面溢出、主要按钮及保留语言的返回链接。已检查开始、键盘/踏板响应、暂停/继续、指南弹层和大厅往返。

未使用实体手机验证多指触摸，未在浏览器中手动通关全部八关。内置预览浏览器不允许 `file://` 导航，因此直接双击打开仅做了相对资源路径与普通脚本检查；HTTP 静态访问已实测。测试脚本的驾驶流程是确定性模拟，不等同于所有设备上的完整实玩。
