# 俄罗斯方块

入口：`index.html`，已在根目录 `gamelist.js` 登记。使用原生 HTML、CSS 和普通 JavaScript 脚本，无构建步骤、外部资源或运行依赖。

- 左右方向键 / A、D：移动；上方向键 / W、X：顺时针旋转；Z：逆时针旋转。
- 下方向键 / S：加速下落；空格：落到底；P / Esc：暂停或继续。
- 屏幕按钮支持点击，左右和向下支持长按。离开窗口或切换标签页会自动暂停。
- 七种方块按七袋随机生成，带落点预览、贴墙旋转、落地调整时间、消行计分和逐级加速。
- 最佳分数保存在当前浏览器本地；存储不可用时仍可正常游戏。
- 共用站点八国语言，切换语言保留本局状态，返回链接携带语言。
