# 纸间升级 · 拖拉机

单人双副牌升级：玩家与对面的电脑队友「青禾」搭档，对抗「阿棠」和「小满」。已加入大厅的「棋牌」分类。

直接打开 `index.html`，或从项目根目录 `games.html` 进入。原生 HTML、CSS、JavaScript；无构建、后端、联网牌局或外部素材依赖。

## 操作

- 点「开始发牌」，轮流选择亮主、反主或不亮。
- 玩家坐庄时获得底牌，选出恰好 8 张后「确认扣底」。
- 点选手牌，选中的牌会抬起，再点「出牌」；可清空选择。
- 「提示」只选中建议牌，不替玩家提交。牌型、跟门、跟对子和拖拉机均有合法性检查。
- 「上一墩」查看四家出牌、赢家和分值；「?」查看完整规则；「Ⅱ」暂停。
- Tab 导航、Enter/空格操作牌与按钮。未聚焦按钮时 Enter 提交，H 提示。弹层、后台标签页会暂停电脑。
- 操作后自动保存牌局和双方等级，刷新后点「继续对局」。存储不可用时仍可游玩。
- 八国语言沿用全站设置；游戏不另设语言开关，返回大厅携带语言参数。

## 本版规则

两副共 108 张牌，每人 25 张、底牌 8 张。对家同队，双方从 2 起，先升过 A 的队伍获胜。

发完牌后依次亮主。强度为单张级牌、同花色级牌对、小王对、大王对；必须持有对应牌，只能用更强的声明覆盖，不按花色再比较同强度。本人可加固相同花色。连续三家不亮后确定；四家都不亮时，翻原底牌中第一张非王牌定主。首局最后亮主者坐庄，无人亮主时玩家默认坐庄；后续庄家由上一局结果决定。

主牌顺序为大王、小王、主花色级牌、其他级牌、主花色 A 至 2（跳过级牌）。其他级牌之间等大，先出者优先。同点同花色两张为对子；同门连续对子为拖拉机，跳过级牌原来的位置。主牌 A 可接副级牌，副级牌可接正级牌，再接小王、大王；无主时级牌可接小王。两个等大的副级牌对子不能互接。

庄家拿底后扣回任意 8 张并先出。仅支持单张、对子、拖拉机首出，不含混合甩牌。必须跟足首门、跟相同张数；不足时跟出所有该门再垫牌。有对子必须跟对子；对拖拉机优先跟可组成的最长连对，再跟剩余连对和对子。缺门时只有相同牌型、相同长度的全主牌才可毙牌，杂牌与不连续对子不能毙拖拉机。每墩赢家下一墩领出。

5 为 5 分，10、K 各 10 分，总计 200 分，只累计抓分方得分。抓分方赢末墩时，底牌分另乘倍数加入：单张 ×2、对子 ×4、n 对拖拉机 ×2ⁿ⁺¹。守庄方赢末墩不计底牌分。

| 抓分方总分（含抠底） | 结果 |
| --- | --- |
| 0 | 守庄方升 3 级 |
| 1–39 | 守庄方升 2 级 |
| 40–79 | 守庄方升 1 级 |
| 80–119 | 抓分方上庄，等级不变 |
| 120 起 | 抓分方上庄，每比 80 多 40 分升 1 级 |

守庄成功由庄家对家接庄；否则庄家下家接庄。没有炒底、关级或甩牌罚分。这是明确边界的休闲双升规则，不代表所有地方或竞赛规则。基本牌制与术语参考[游戏茶苑的升级说明](https://www.gametea.com/games/shengjiyouxi.html)；亮主时机、主牌连对及抠底倍数以本页和游戏内说明为准。

## 实现

- `engine.js`：独立规则与电脑策略，同时支持浏览器普通脚本和 Node。
- `game.js`：交互、电脑定时行动、保存恢复、弹层和响应式手牌。
- `translations.js`：八国语言的静态、动态、说明和无障碍文案。
- `cover.svg`：本地绘制的纸牌封面；牌桌、头像和牌面使用 CSS/SVG。

电脑通过 `view(state, player)` 接收自己的牌、各家张数、公开出牌、庄家、主牌与分数，不接收其他手牌、底牌或洗牌种子。策略会保对子扣底、优先连对、让牌给队友并争取有分的墩；不是搜索全部隐藏牌的完美策略。

## 验证

```sh
node --test games/tractor/engine.test.js
```

8 项引擎测试覆盖牌制、主牌大小、拖拉机、跟牌约束、毙牌、平手、亮主、扣底、升级阈值、末墩倍数、电脑信息隔离和存档。200 个固定种子的整局模拟累计 3,773 墩、92 次拖拉机首出，逐步校验合法性与 108 张牌守恒。

浏览器布局检查覆盖 320×568、360×640、390×844、568×320、844×390、768×1024、1024×768、1280×720、1920×1080；核心操作位于视口内，整页无横向或纵向溢出。八国语言在 320×568 检查通过。已检查桌面、小竖屏和短横屏截图，手牌在竖屏自动分排。

浏览器实际走通发牌、亮无主、33 张手牌扣底、选牌提示、出牌与跟牌、完整结算、升至 3 后由队友接庄、暂停、刷新恢复，以及大厅搜索和往返；未观察到脚本错误。八语共 792 条文案检查了键与替换参数一致性。大厅字体已补齐原字体支持的新增字符，并同步两个缓存版本 URL。

所有资源使用相对路径与普通脚本，无本地数据 fetch。浏览器实测使用本地 HTTP。内置浏览器安全策略拒绝 `file://` 协议，未实测双击打开；已检查对应静态加载方式。
