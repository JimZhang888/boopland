# 水彩分类

在玻璃瓶之间倒水，把每一种颜色归到一个瓶子里。入口为 `index.html`，已登记到大厅的「益智」分类。沿用纸张、铅笔轮廓和柔和水彩配色，使用原生 HTML、CSS、JavaScript 和 SVG，无构建步骤或外部依赖。

## 玩法与操作

- 先点源瓶，再点目标瓶；再次点击源瓶或按 Esc 取消选择。
- 只能倒入空瓶，或顶部颜色相同且未满的瓶子。一次转移顶部连续同色，数量不超过目标剩余容量；每个瓶子可装四层。
- 所有非空瓶都装满一种颜色时通关。24 关由三色逐渐增加到七色，每关保留两个空瓶；所有初始局面均有经过验证的解法。
- 无倒计时。支持不限次撤回、当前局面提示、重开、关卡解锁和每关最少步数记录。提示按分片搜索，搜索超限或未找到解法时提示撤回或重开，不将搜索超限判定为无解。
- 鼠标和触屏均用点选；Tab / 方向键移动焦点，Enter / 空格选瓶，U 撤回。
- 默认显示颜色辅助符号，可在右上角切换。遵循减少动态效果偏好。
- 当前局面、已解锁关卡、最佳步数与符号偏好保存在当前浏览器的 `boopland-water-sort-v1` 中；存储不可用时仍可游玩。
- 共用项目八国语言与返回链接参数，不增加游戏内语言切换入口。

## 文件

- `engine.js`：纯规则、合法倒水、胜利判定、可分片执行的提示搜索、历史回放。
- `levels.js`：24 个固定谜题及其可执行解法，瓶内数组按从下到上排列。
- `game.js`：界面、动画、输入、存档与弹层。
- `translations.js`：八国语言的静态与动态文案及无障碍标签。
- `cover.svg`、`paper.svg`：独立的手绘封面与纸纹。
