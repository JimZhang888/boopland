# 九宫格探险 · 迷雾篇

Boopland 的原生静态翻格子探险游戏，入口为 `index.html`，已登记到根目录 `gamelist.js`。使用纸张底色、原创 SVG 铅笔图标、八国语言，以及随可见高度调整的手机横竖屏布局。不依赖构建步骤、远程字体或 CDN。

本目录为独立的“迷雾篇”，与 `games/nine-grid/` 的回合移动版本分开维护。

## 玩法

- 点任意迷雾格发现事件，可以切换到其他格，稍后再处理已发现的事件。
- 每层九格：中央营地、上方守卫、两只魔物、一个宝箱、一处清泉、荆棘宝藏、随机奇遇和商人。
- 完成四个非营地事件后解锁守卫。可继续收集资源，也可以直接挑战。击败守卫后三选一升级，挑战共五层。
- 战斗自动结算，战前显示总伤害。玩家先手，敌人受到致命攻击后不反击；每次反击至少造成 1 点伤害。
- 蓄力使本场攻击 +3，每层一次。药水恢复 12 生命；每层营地可恢复 7 生命一次。清泉可立即恢复 16 生命，或装成一瓶药水。
- 商人只出售一件商品：7 金币买药水，10 金币增加 1 攻击。随机奇遇包括生命换攻击、金币换护甲、概率蘑菇和旅人礼物。
- 每层有环境规则：微风无加成、荆棘使陷阱伤害 +2、浓雾使敌人生命 +3、顺风使宝箱金币 +4、长夜使敌人攻击 +1。
- 战后升级：攻击 +2 或护甲 +1，并恢复 6 生命；也可选生命上限 +6 并恢复 14 生命。
- 积分 = 击败守卫数 ×100 + 完成探索格数 ×10 + 剩余金币。通关额外获得 200 + 剩余生命 ×5；营地不计探索格。
- 键盘 `1–9` 对应九格，`H` 使用药水，`Esc` 退出当前事件或关闭对话框。鼠标和屏幕点击均可操作。游戏为回合制，没有计时压力。

## 保存与运行

可直接打开 `index.html`，或通过普通静态服务器访问。所有资源使用相对路径；返回大厅会保留全局语言设置。

本局进度、随机数状态和最佳成绩分别保存在本机 `localStorage`，不会与回合移动版本共用存储键。每次操作后保存，刷新继续；存档损坏时开始新局，存储受限时仍可正常游玩。

源文件：`engine.js` 管理规则与存档校验，`game.js` 管理交互，`translations.js` 包含八国语言，`style.css` 管理响应式布局，SVG 图形内嵌在 HTML 中，`cover.svg` 用于大厅。
