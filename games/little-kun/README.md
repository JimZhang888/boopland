# 小鱼化鲲

大鱼吃小鱼的成长小游戏。纸张纹理、铅笔线稿、低饱和海水与六种手绘形态；原生 HTML / CSS / JavaScript，Canvas 绘制，无第三方资源、构建步骤或运行依赖。

从项目根目录 `games.html` 搜索「小鱼化鲲」进入，或直接打开本目录 `index.html`。所有资源均用相对路径，接入全站八国语言、返回大厅和统计加载器。

## 操作与手感

- 桌面：鼠标指引游动，或者 WASD / 方向键；空格或按钮冲刺。
- 手机：在海面任意位置按住并拖动浮动摇杆，松开停止；另一只手可同时点冲刺。
- 输入采用按时间计算的加速、快速制动和转向缓动，斜向速度归一化。摄像机柔和跟随，海域可无限探索；手机适当放大鱼体。
- P / Esc 或顶部按钮暂停；切换窗口、隐藏页面、打开说明会暂停。暂停时清空输入、停掉帧循环，恢复不会补算离开的时间。
- 音效默认关闭，可手动开启。声音由 Web Audio 合成，不需要音频文件。

## 成长与难度

| 形态 | 累计成长值 | 基础体型 |
| --- | ---: | ---: |
| 豆丁鱼 | 0 | 18 |
| 青鳞鱼 | 16 | 27 |
| 飞翅鱼 | 48 | 39 |
| 巨齿鲨 | 102 | 56 |
| 深海鲸 | 190 | 78 |
| 北冥鲲 | 320 | 110 |

- 体型不超过玩家 91% 的鱼可以吃，达到玩家 112% 的鱼会造成伤害并显示「!」；体型接近的鱼互不伤害。成长保留场上鱼的原体型，曾经的威胁会变成食物。
- 食物约占新鱼的 78%，随视野维持 27–44 条鱼。新增鱼从视野边缘游入，开局大鱼至少远离玩家 350 单位，前 7 秒不主动追击。
- 大鱼短追击 1.1 秒，然后休息；追击速度低于玩家正常游速。玩家有四格生命，受伤后保护 2.4 秒，成长值不倒退。
- 冲刺持续 0.3 秒，速度约 ×2.6，同时免疫碰撞伤害；消耗 30 能量，冷却 0.7 秒，每秒回复 24 能量。
- 进化恢复一格生命、补满能量，并保护 2.5 秒；珍珠恢复一格生命和 35 能量，低血量时补给更频繁。
- 按猎物体型提供成长值。连续 3.8 秒内进食累计连吃，每四次提高 0.5 倍得分，最高 ×3。没有生存倒计时或饥饿衰减。
- 第六形态触发化鲲结算。选择「化鲲遨游」可继续游玩：所有鱼均可吞食，不再受伤，空格变为消耗 50 能量的「北冥吞潮」，吸入附近 410 单位内的鱼群。
- 最佳得分与最高形态保存到 `boopland-little-kun-v1`；本局不跨刷新续玩。存储被禁用或数据损坏时仍能游玩。
