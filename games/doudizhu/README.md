# 斗地主

原生 HTML、CSS、JavaScript 的单机斗地主：一名玩家与两名电脑牌友对战。入口为 `index.html`，已登记至大厅「棋牌」分类，支持搜索「斗地主」或当地语言名称。所有资源使用相对路径，不需要后端、构建工具或在线素材。

## 玩法

- 54 张牌，每人 17 张，留下 3 张地主底牌。按顺序不叫或叫 1、2、3 分，只能提高叫分；3 分立即确定地主，全不叫则允许重新发牌。地主获得底牌并先出，新局轮换首先叫分的座位。
- 支持单张、对子、三张、三带一、三带二、顺子、连对、飞机、飞机带单、飞机带对、四带二单、四带两对、炸弹、火箭，共 14 类牌型。
- 普通接牌必须同类型、同张数、同连续组数且主牌点数更大。炸弹能压普通牌，火箭最大。连续两人不出，上一位出牌者获得自由领出权。
- 顺子至少 5 张，连对至少 3 对，飞机至少 2 组连续三张；这些连续牌型的主体不能包含 2 或王。
- 本桌采用明确的翅膀约定：飞机单翅膀允许成对，但不能组成三张或炸弹，且不能与主体同点数；对子翅膀使用不同点数的对子。四带二单可以带一个对子。四带二不视作炸弹。规则弹层提供相同说明。
- 地主先出完则地主赢；任意农民先出完则两位农民共同赢。炸弹/火箭每次翻倍；地主获胜且农民都未出过牌为春天；农民获胜且地主只出过一次为反春天，均再翻倍。地主得失两份，农民各一份，三人积分总和为零。
- 电脑基于自己的手牌、公开身份、上一手出牌和对手余牌数决策，不读取对手牌面；优先较长组合，保留大牌和炸弹，农民通常不压队友牌，能出完时优先获胜。它是启发式电脑，不是最优解求解器。

## 操作与状态

- 点击纸牌选中，再点击「出牌」；点击已选牌取消。合法性即时反馈，非法牌不能提交。
- 「提示」循环展示合法建议，「重选」清空选择；新一轮领出时不能「不出」。
- 方向键移动手牌焦点，Enter/空格切换选牌；焦点不在按钮或链接上时 Enter 出牌，H 提示，Esc 清空。主要操作均有可点击按钮。
- 打开规则或重开弹层、切到后台时暂停电脑回合。确认重开会放弃当前局而保留总分。
- 自动保存牌局和总分，刷新、返回大厅后可续局。保存的是随机种子、起始座位和合法动作序列；恢复时重新执行规则验证，拒绝非法存档。结算与已计分标记一并保存，刷新不会重复加分。存储不可用时仍可游玩。
- 存储键：`boopland-doudizhu-v1`。没有联网对战、账户或真实金额。

## 界面与集成

- 纸纹背景、铅笔线条、纸牌和兔/猫牌友，配合低饱和绿与豆沙红，延续项目默认风格。
- 手机竖屏大手牌分为两排；短横屏使用单排与紧凑牌桌。常见尺寸无需页面滚动。小于正常支持范围的竖屏允许受控滚动，保留操作可达性。
- 共用根目录 `i18n.js`，覆盖中文、英文、日文、韩文、法文、德文、西班牙文、巴西葡萄牙文。包含动态状态、牌型、弹层、无障碍标签和大厅简介；游戏不另设语言切换入口。切换语言保留牌局，返回大厅携带语言参数。
- 引入公共 `analytics.js`；本地文件和回环地址按公共脚本约定跳过统计。
- 本次大厅登记所需的字体字符已检查并补充到大厅字体子集，预加载和字体引用版本保持一致。

## 文件

- `engine.js`：可在浏览器及 Node 使用的纯规则引擎、洗牌、出牌生成、电脑策略与存档回放。
- `game.js`：交互、布局、电脑定时器、弹层和本地存档。
- `translations.js`：八国语言文案。
- `style.css`、`paper.svg`、`cover.svg`：布局、纸纹和独立大厅封面。
- `engine.test.cjs`：规则、模拟对战、存档与集成检查。

## 验证

从项目根目录运行：

```text
node --test games/doudizhu/engine.test.cjs
```

12 项测试通过，包含：54 张牌的完整性、14 类牌型、非法组合、比较规则、叫分和回合控制、两次不出、春天与反春天、炸弹/火箭倍数、零和结算、合法出牌生成与穷举子集对照、农民配合、120 个随机种子的模拟对局、存档准确回放与非法存档拒绝，以及八国语言的键/变量一致性、HTML 资源路径和唯一大厅登记。

通过本机静态服务器进行浏览器实测：叫分成为地主、选牌、提示、重选、出牌、不出、电脑接牌、说明弹层暂停、刷新续局、大厅搜索及往返、整局打完后的胜利结算、刷新不重复计分、再来一局。控制台未发现脚本错误。

实测尺寸：320×568、360×640、390×844、568×320、844×390、768×1024、1024×768、1280×720、1920×1080，主要操作均在屏内且页面没有横纵溢出。另对 20 张手牌在八国语言下检查 320×568、390×844、568×320，共 24 组；待旋转后的手牌重排完成再测量。小屏装饰文案曾与回合提示重叠，已压缩装饰并复查；弹层内容内部滚动，关闭按钮和返回链接保持可达。

未实测：实体手机触屏及安全区、跨标签页实时切换语言。浏览器工具禁止 `file://` 导航，因此直接双击方式仅检查相对资源与无服务器依赖，未作浏览器实测。春天、反春天、所有牌型边界和全不叫由引擎测试覆盖，未逐一人工打出。
