# 发条小镇 / Clockwork Town

一款原创、轻量的点击式机械解谜小游戏。借鉴场景探索、组合道具和修复机关的玩法，沿用 Boopland 的纸张、铅笔线稿与低饱和色彩；角色、场景和素材均在本目录内原创绘制。

## 运行与入口

- 大厅：根目录 `games.html`，推荐区可直接进入，或在解谜分类下搜索「发条小镇」。
- 独立入口：`games/clockwork-town/index.html`。
- 原生 HTML / CSS / JavaScript，普通脚本、相对资源路径，无安装、构建、CDN 或后端依赖。
- 全站语言由 `../../i18n.js` 统一管理，支持八国语言。游戏内不另设语言选择器。

## 玩法

- 点击带小圆点的物件进行观察、收集或操作。支持鼠标点击、触摸点击和 Tab / Enter 键盘操作。
- 点击场景空白处可左右移动；点击物件时，阿铜会自动走到旁边，不需要先手动走近。大门整个门板都可点击。
- 选择口袋中的物品，再点击场景中的目标使用；选择另一件物品可尝试组合。重复选择或按 Esc 取消选择。
- 点击排水沟可查看近景和缺少的工具；收齐磁铁、细绳后，也可以在近景里直接组合钓线、取出齿轮。已有钓线时，无论是否选中，都有明确的钓取入口。
- 取得齿轮后可直接点「去大门装上齿轮」；也可以稍后点击大门，在近景中点「装上齿轮」。刷新后未选中的齿轮仍可安装；还没有齿轮时，大门会明确提示下一步。
- 「伸长身体」可以够到工坊高处的油壶。
- 点击机械锁、管道面板、灯座、水泵、吊桥天平和信号台打开交互谜题。关闭弹窗不会丢失已经调整的状态；新谜题也提供单独重置。
- 六处场景在解锁后可以往返；错误使用不消耗物品，无失败、倒计时或不可逆死局。遗漏的钥匙和发条可以回到前一章补取。
- 手记记录目标、六项里程碑、墙上刻痕和车站时刻表；章节地图可直接前往已解锁场景。提示按当前进度逐级展开，每个步骤两级。
- 音效默认关闭，由玩家主动开启。页面隐藏时暂停声音和装饰动画，遵循减少动态效果设置。
- 自动存档继续使用 `boopland-clockwork-town-v1`，保存合法操作序列，通过规则回放恢复进度；原三章通关存档可直接进入温室，无需重开。新增水量、配重及未输完的信号也会保存；存储不可用时仍可游玩，并显示未保存提示。

## 六章旅程

1. 废料庭院：收集磁铁、细绳，组合磁力钓线，从排水沟取出带铁芯的黄铜齿轮；安装齿轮，根据墙上刻痕解开密码锁。
2. 蒸汽工坊：伸长身体取油，润滑飞轮；旋转 3 × 3 管道连接进出口，恢复蒸汽动力，再从抽屉取得透镜。
3. 微光钟楼：安装透镜，调整三面反射镜，点亮钟楼，发现通往温室的新路。
4. 雨滴温室：寻找金属曲柄与木柄，组合并安装水泵摇柄；让三只水罐之间的水量达到苗箱需要的刻度，取出叶纹钥匙。
5. 悬铃吊桥：用钥匙打开配重柜，按重量与支点距离交换四块砝码；平衡后拉下桥杆，从对岸工具箱取得盘卷发条。
6. 星邮车站：安装发条唤醒车站，参照旧时刻表输入五个图案信号，再亲手让邮车出发。完成六章后可以自由回访或重玩。

## 文件

- `engine.js`：独立规则、管道连通、光路追踪、水量转移、配重力矩、图案序列、渐进提示和存档回放。
- `art.js`：原创 SVG 场景、角色、道具和可交互物件的位置。
- `game.js`：界面、键盘焦点、音效、存档与场景尺寸适配。
- `translations.js`：八国语言的静态文案、动态反馈、提示和无障碍标签。
- `chapters-i18n.js`：续章的八国语言文案，由 `translations.js` 合并到同一命名空间。
- `cover.svg`：由庭院场景绘制的大厅封面。
- `engine.test.cjs`：六章通关、前置条件、错误道具、返回取物、管道/光路、水量可解性、旧存档续玩、谜题中途恢复、提示、语言与集成资源检查。
