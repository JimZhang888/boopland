# 发条小镇 / Clockwork Town

一款原创、轻量的点击式机械解谜小游戏。借鉴场景探索、组合道具和修复机关的玩法，沿用 Boopland 的纸张、铅笔线稿与低饱和色彩；角色、场景和素材均在本目录内原创绘制。

## 运行与入口

- 大厅：根目录 `games.html`，推荐区可直接进入，或在解谜分类下搜索「发条小镇」。
- 独立入口：`games/clockwork-town/index.html`。
- 原生 HTML / CSS / JavaScript，普通脚本、相对资源路径，无安装、构建、CDN 或后端依赖。
- 全站语言由 `../../i18n.js` 统一管理，支持八国语言。游戏内不另设语言选择器。

## 玩法

- 点击带小圆点的物件进行观察、收集或操作。支持鼠标点击、触摸点击和 Tab / Enter 键盘操作。
- 选择口袋中的物品，再点击场景中的目标使用；选择另一件物品可尝试组合。重复选择或按 Esc 取消选择。
- 点击排水沟可查看近景和缺少的工具；收齐磁铁、细绳后，也可以在近景里直接组合钓线、取出齿轮。已有钓线时，无论是否选中，都有明确的钓取入口。
- 「伸长身体」可以够到工坊高处的油壶。
- 点击机械锁、管道面板和灯座打开交互谜题。关闭弹窗不会丢失已经调整的状态。
- 三处场景在解锁后可以往返；错误使用不消耗物品，无失败、倒计时或不可逆死局。
- 手记记录目标、里程碑和墙上刻痕；提示按当前进度逐级展开，每个步骤两级。
- 音效默认关闭，由玩家主动开启。页面隐藏时暂停声音和装饰动画，遵循减少动态效果设置。
- 自动存档使用 `boopland-clockwork-town-v1`，保存合法操作序列，通过规则回放恢复进度；存储不可用时仍可游玩，并显示未保存提示。

## 三处场景

1. 废料庭院：收集磁铁、细绳，组合磁力钓线，从排水沟取出带铁芯的黄铜齿轮；安装齿轮，根据墙上刻痕解开密码锁。
2. 蒸汽工坊：伸长身体取油，润滑飞轮；旋转 3 × 3 管道连接进出口，恢复蒸汽动力，再从抽屉取得透镜。
3. 微光钟楼：安装透镜，调整三面反射镜，点亮钟楼。通关后可自由回看场景或重玩。

## 文件

- `engine.js`：独立规则、管道连通、光路追踪、渐进提示和存档回放。
- `art.js`：原创 SVG 场景、角色、道具和可交互物件的位置。
- `game.js`：界面、键盘焦点、音效、存档与场景尺寸适配。
- `translations.js`：八国语言的静态文案、动态反馈、提示和无障碍标签。
- `cover.svg`：由庭院场景绘制的大厅封面。
- `engine.test.cjs`：完整通关、前置条件、错误道具、返回取物、管道/光路、存档回放、提示、语言与集成资源检查。

## 验证

在项目根目录运行：

```sh
node --test games/clockwork-town/engine.test.cjs
```

已通过 10 项自动测试及 JavaScript 语法检查。浏览器中实际完成了收集、组合、密码锁、取油、管道、透镜、反射镜与通关；验证了刷新恢复、重开/取消重开、大厅搜索与往返、欢迎页跨标签页语言同步且道具保留。

针对第一关齿轮拾取，补充验证了取消选中钓线后刷新恢复、直接从排水沟近景取物、缺少工具的分步反馈、近景组合钓线，以及取得齿轮后打开工坊大门。手机 `320×568` 实点了磁铁、细绳与排水沟；`568×320` 横屏完成取物。法语、德语在这两种尺寸下的钓取按钮也保持完整可见，页面没有溢出。

已在桌面 Chromium 内嵌浏览器检查以下 CSS 视口，游戏页面无横纵向溢出，主要按钮没有越出视口：

`320×568`、`360×640`、`390×844`、`568×320`、`844×390`、`768×1024`、`1024×768`、`1280×720`、`1920×1080`。

八种语言均在 `320×568` 复查，无页面溢出；手机布局采用四个较大道具格，足以容纳本作最多同时持有的两件物品。长说明允许在弹窗内滚动。极端小窗口或辅助功能大字号优先保留内容可达性。

验证限制：没有进行 iOS / Android 真机测试；当前浏览器工具禁止 `file://` 导航，因此双击模式未实测，仅完成相对资源、普通脚本及无网络数据依赖检查。HTTP 静态服务访问已实际验证。
