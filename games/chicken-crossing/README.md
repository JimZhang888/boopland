# 小鸡过马路

参考 [Crossy Road](https://www.crossyroad.com/) 的逐格穿越玩法，使用本项目的纸张、铅笔轮廓和低饱和配色独立绘制场景与封面。没有使用原作的图片、音频或商标素材。

## 运行与接入

- 入口：`games/chicken-crossing/index.html`；已在根目录 `gamelist.js` 登记，分类为「动作」。
- 原生 HTML / CSS / JavaScript，无构建、第三方库、CDN 或数据请求；资源均使用相对路径。
- 可从大厅搜索「小鸡过马路」进入；返回大厅保留全局语言参数。
- 引入项目的 `i18n.js` 与 `analytics.js`。支持中文、英文、日文、韩文、法文、德文、西班牙文和巴西葡萄牙文；语言入口仅位于欢迎页。

## 操作与规则

- 方向键或 WASD：向相应方向跳一格，长按连续跳；空格向前。P / Esc 暂停或继续。
- 轻点画面向前，滑动选择方向；也可点按或长按屏幕方向键。
- 躲避车流；铁路在列车进入前持续预警 2.1 秒。红灯点亮时先在草地等待。
- 河面必须落在漂木上，站稳后会跟随木头横向移动；漂出边界、落水、撞车或被火车撞到都会结束本局。
- 树与石头阻挡移动。得分只统计到达过的最远行数，后退再前进不会刷分。每 25 步显示里程提示。
- 18 秒内必须到达更远的一行；12 秒后显示剩余时间。暂停不消耗时间，隐藏页面或失焦自动暂停。
- 每局随机路线，随距离适度增加难度。连续危险地形不超过三行，草地保留中央通道；远处提前生成，身后及时回收。
- 最佳成绩键：`boopland-chicken-crossing-best-v1`；音效偏好键：`boopland-chicken-crossing-sound`。存储不可用时仍可正常游玩。音效默认关闭，由用户交互启动。

## 文件

- `engine.js`：独立模拟、路线生成、移动、漂流、碰撞与计分；可通过 CommonJS 在 Node 中验证。
- `scene.js`：Canvas 手绘场景、汽车、火车、木头、小鸡与纸纹；按 DPR 绘制，窗口改变时保留本局。
- `game.js`：键盘与指针输入、弹层、音效、存储、语言刷新及页面生命周期。
- `translations.js`：八国语言的静态文案、动态状态与辅助标签。
- `cover.svg`、`chicken.svg`、`paper.svg`：本地原创矢量资源。
