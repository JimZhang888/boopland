# 纸上贪吃蛇

暖色方格纸、铅笔排线的小蛇、红色苹果与手绘纸片界面。纯 HTML / CSS / JavaScript，无构建步骤、外部字体或第三方素材依赖。

从根目录 `games.html` 进入，或打开本目录 `index.html`。游戏已登记到 `gamelist.js`，带独立 SVG 封面，所有资源使用相对路径。

## 操作与规则

- 点击「开始涂鸦」开始；方向键、WASD、屏幕方向按钮或棋盘滑动转向。
- 空格、P、Esc 或暂停按钮暂停 / 继续；失去窗口焦点、切换标签页、打开说明时自动暂停。
- 每个苹果 10 分，身体增加一格；碰壁或碰到自身结束，填满 20 × 20 棋盘获胜。
- 三档固定速度：慢慢来 200ms / 格、刚刚好 140ms / 格、快一点 95ms / 格。开局后锁定速度，各档分别保存最佳成绩。
- 重开按钮回到准备状态，可重新选择速度。音效默认关闭，由用户交互启用。
- 共用全站八国语言；切换不重置当前游戏，返回大厅链接携带语言。未提供独立语言切换入口。
- 最佳成绩保存在 `boopland-paper-snake-best-v1`；存储受限时退回本次访问内的记录。

## 验证

在项目根目录执行 `node --test games/paper-snake/engine.test.cjs`。8 项测试覆盖计分与食物位置、连续转向与禁止掉头、碰壁 / 自身碰撞、移入离开的尾格、满盘胜利、暂停计时、三档速度与卡顿处理、重新开始。

实际浏览器检查：

- 中文准备界面：320 × 568、360 × 640、390 × 844、568 × 320、844 × 390、768 × 1024、1024 × 768、1280 × 720、1920 × 1080，无页面溢出，主要操作可见。
- 八国语言在 320 × 568 与 568 × 320 下的准备界面，以及标题、按钮和链接语言。
- 开始、暂停、恢复、碰壁结算、重开、说明弹窗、音效开关；大厅搜索、进入与返回。
- 56 个文案键在八种语言中齐全，变量占位一致；静态资源和封面路径有效；HTTP 预览未发现脚本错误。

验证限制：内置浏览器安全策略禁止 `file://` 导航，因此双击文件运行仅检查了实现和相对资源路径，未直接实测。未使用实体触摸设备，也未实际打满全部 400 格（满盘由规则测试覆盖）。
