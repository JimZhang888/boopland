# 九宫格探险

一个原生 HTML / CSS / JavaScript 回合制小游戏，沿用 Boopland 的纸张、铅笔线稿与低饱和配色。地图、旅人、怪物和封面均为本目录独立 SVG 图形，无图片 CDN、构建步骤或后端依赖。

## 运行与操作

从大厅搜索「九宫格探险」进入，或在浏览器打开本目录 `index.html`。资源使用普通脚本和相对路径。

- 点击上下左右相邻格，或用方向键 / WASD 移动。不能斜走。
- 遭遇怪物后选择攻击、防守反击或撤退，也可用 1 / 2 / 3。
- H 或药水按钮恢复生命。右上角 ? 打开指南，↻ 重新开始；正在游玩时重开需要确认。
- 没有计时和自动推进，可以随时停下来思考。
- 共用根目录 i18n.js 的八国语言，语言入口仅在欢迎页。返回链接携带语言，语言变化只重新绘制文字，不重置引擎状态。

## 玩法

起始 32 生命、12 口粮、5 攻击、2 瓶药水。每层九格，底部中央为营地，顶部中央为石门，其余为 3 个怪物、2 个宝箱和 2 个补给。第一层固定用于认识规则，后续四层随机排列。

移动消耗 1 口粮。口粮为零时，移动改为消耗 3 生命；移动费用在抵达并获得补给前结算。已探索格不会重复给予奖励。

普通攻击后，存活的敌人反击；每第三次反击为双倍攻击。防守造成一半攻击力伤害（向下取整，至少 1），额外减伤 3；护甲直接减伤，敌人反击最低 1。撤退承受普通攻击并支付移动费用，回到进入战斗前的格子，敌人剩余生命和攻击轮次保留。药水恢复至多 14 生命，不推进战斗回合。

宝箱可选攻击 +1、护甲 +1，或药水 +2 与金币 +15。装备持续整个旅程。补给恢复至多 9 生命、5 口粮。每层击败任意一只怪物获得本层通行符，可选择继续探索或进入下一层；跨层恢复至多 4 生命、4 口粮。第五层石门有最终守卫，击败即通关。

分数 = 金币 + 击败怪物数 × 15 + 首次访问格数 × 5 + 已通过层数 × 60 + 通关时剩余生命 × 2。最佳成绩在结算时存入本浏览器，存储异常不阻止游玩。本局进度不持久化。

## 验证

运行：`node --test games/nine-grid/engine.test.cjs`。

9 项测试覆盖移动边界、锁门、阶段锁定、一次性奖励、升级跨层、普通/重击/防御结算、击杀免反击、药水、撤退、饥饿死亡顺序、最终守卫、终态不可操作、1,000 层生成结构、随机种子复现、八国语言插值一致性、相对资源及唯一大厅登记。

内置浏览器已实际验证：开始、宝箱三种选项、补给、普通攻击、防守、撤退、药水、键盘移动和战斗、指南开关、重开取消、失败后重开、完整五层通关与结算、刷新保留纪录、大厅搜索与往返、链接语言保留。

检查的 CSS 视口：320×568、360×640、390×844、568×320、844×390、768×1024、1024×768、1280×720、1920×1080。棋盘按可用宽高容纳，不出现页面横纵滚动；必要状态、返回与战斗操作可见。八国语言另检查小竖屏的开始/宝箱和短横屏的战斗状态，修复长标题挤压棋盘的问题。小屏说明在弹层内滚动。

验证限制：未使用真实手机触屏硬件。内置浏览器策略禁止 file:// 导航，因此直接双击运行仅检查了静态结构、资源路径和普通脚本兼容性，未做浏览器实测。极小窗口或辅助文字放大时允许受控滚动。
