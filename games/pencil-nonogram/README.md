# 铅笔数织

根据行、列数字填格，逐渐显现小猫、盆栽、咖啡杯等日常图案。沿用项目的暖白纸张、铅笔排线与低饱和配色；通关图案自动收入收藏图鉴。

## 运行

直接打开 `index.html`，或从大厅的「益智」分类进入。全部资源使用相对路径和普通脚本，无构建、服务端、CDN 或数据请求。封面和大厅八国语言名称登记于根目录 `gamelist.js`。

## 内容与操作

- 12 个原创图案，三个章节：4 页 5×5、4 页 8×8、4 页 10×10。每页均已验证唯一解，并可通过行列候选排除求解，无需猜测。
- 数字代表连续填色的格数，各段之间至少空一格；数字顺序分别从左到右、从上到下。0 表示整行或整列为空。
- 点击或拖动填色，重复点击同类标记可擦除。手机使用「填色 / 画叉 / 擦除」工具，桌面支持右键画叉。
- 撤销以一次完整拖动为单位。检查标出错误的填色或叉号；提示修正或补上一格，记录使用次数，均不限次数。
- 方向键移动焦点，空格填色，X 画叉，Delete / Backspace 擦除，Ctrl / ⌘ Z 撤销；Enter 使用当前工具。
- 正确填满图案即可通关，不强制标记全部空白。成功后显示彩色铅笔图案，可继续下一幅未收藏图案或查看图鉴。
- 自由换页，每页分别保存进度；重画只清空本页笔迹、用时、提示次数，已经收藏的图案保留。全收集后可继续重玩。
- 图鉴、各页进度与成绩保存在当前浏览器的 `boopland-pencil-nonogram-v1`。存储不可用时仍可游玩，并显示不能持久保存的提示。
- 计时在弹层、失焦和后台时暂停；不计入离线时间，无限时或生命限制。

## 文件

- `puzzles.js`：图案和章节数据。
- `engine.js`：行列线索、候选排列、判定和提示逻辑；也可通过 CommonJS 加载进行验证。
- `game.js`：输入、撤销、持久化、收藏、弹层和响应式棋盘。
- `translations.js`：通过全局 `BooplandI18n` 注册八国语言，不提供独立语言切换器。
- `style.css`、`cover.svg`：独立纸张视觉、响应式样式及大厅封面。

- 选关、通关、图鉴、重画、刷新后恢复；大厅搜索、进入及返回时保留语言。
- 所有八种语言 × 5×5 / 8×8 / 10×10 棋盘 × 9 种视口，共 216 项一屏布局检查。

- `file://` 直接打开、带子路径的静态服务器、损坏存档恢复、禁用 localStorage 后降级；无脚本异常或缺失资源。
