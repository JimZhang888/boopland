# 一笔修路

纯静态路线规划小游戏。入口 `index.html`；也可以从项目大厅搜索「一笔修路」进入。不需要安装依赖或构建，素材均为本地 SVG/CSS。

## 玩法

- 从绿色起点沿格点上下左右修路，经过所有房屋后抵达旗帜；不要求走遍空地。
- 避开树木、石头和池塘。道路不能交叉或重复访问格点。
- 鼠标或触摸拖动、逐格点击均可。松手后可以从道路末端续画。沿原路退一步擦掉最后一段。
- 撤销、重画、参考路线提示、12 关自由选关。没有计时或提示惩罚。
- 目标步数以内获得三星，多走不超过四步获得两星，其余一星。目标来自一条已验证的参考路线，不宣称是全局最短路。
- 聚焦地图后：方向键修路，Backspace / Z 撤销，R 重画，H 提示。
- 本机保存每关最高星数及上次选择的关卡；刷新不保存尚未完成的路线。存储不可用时仍可游玩。
- 接入根目录 `i18n.js` 的八国语言与语言链接传递；游戏内不增加语言切换入口。

## 文件

- `engine.js`：12 关地图、参考路线、合法移动、自交/障碍判断、撤销及星数。
- `game.js`：SVG 手绘地图、指针采样、键盘操作、提示/地图册/帮助和进度保存。
- `translations.js`、`style.css`、`cover.svg`：语言、响应式纸感样式和大厅封面。

- 320×568、568×320、844×390、1280×720 通关布局正常。
- 八国语言分别检查 320×568、568×320，无页面溢出、侧栏与工具栏重叠。
- 点击修路、方向键完成第一关、三星结算、下一关、刷新恢复关卡/星数、地图册选关、撤销、提示开关、短横屏帮助弹窗。
