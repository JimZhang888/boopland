# 争上游

一人对战两位电脑的三人休闲纸牌游戏。纯 HTML / CSS / JavaScript，无安装、构建、联网对局或后端依赖。入口 `index.html`，已登记到大厅「棋牌」分类。

## 本版规则

- 使用完整 54 张牌，每人 18 张，各自为战，按出完手牌的先后排定上游、中游、下游；第二人出完时确定全部名次。
- 点数：3 < 4 < … < 10 < J < Q < K < A < 2 < 小王 < 大王。花色不参与比较。
- 持有梅花 3 的玩家先出，首手必须包含梅花 3。
- 支持单张、对子、三张、三带一、三带一对、至少五张的顺子、至少三对的连对、至少两组连续三张的飞机（不带翅膀）、四张炸弹、双王王炸。
- 顺子、连对、飞机不含 2 或大小王。跟牌须牌型和张数相同、主点数更大。炸弹能压普通牌型，较大的炸弹能压较小炸弹，王炸最大。
- 不使用四带二、带翅膀飞机、进贡或革命；避免混用各地不同规则。
- 领出不能不要。其他玩家都不要后，最后出牌者重新领出；该玩家已出完时，由其顺位下一位仍有手牌的玩家领出。
- 不要不意味着退出本轮，下次轮到时可以继续接牌。

## 操作与功能

点击手牌选中/取消，点击「出牌」提交；「提示」循环推荐合法组合，「清空」取消选择。「不要」仅在跟牌时可用。

键盘支持 H 提示、Esc 清空，以及焦点不在按钮/链接时的 Enter 出牌、空格不要。聚焦按钮时保留浏览器原生键盘操作。

支持暂停、规则弹层、重开确认、整局名次和本地上游次数记录。打开弹层或切走页面时停止电脑计时，返回页面后由玩家继续。存储不可用时仍能正常玩。电脑只依据自己的手牌和公开的剩余张数选择出法，不读取对手的牌面。

沿用全站 `BooplandI18n` 的八国语言与链接语言参数；游戏内不另设语言切换入口。窗口调整保留当前牌局。

## 文件

- `engine.js`：牌型、压牌、合法出法、轮次状态和电脑建议；浏览器普通脚本 / Node CommonJS 双入口。
- `game.js`：牌桌交互、计时暂停、弹层、记录与动态翻译。
- `translations.js`：八种语言，每种 79 个文案键。
- `style.css`、`cover.svg`：响应式纸张牌桌和手绘封面。
- `engine.test.cjs`：规则与完整对局回归测试，仅用于开发。

## 验证（2026-11-09）

在项目根目录运行 `node --test games/climb-up/engine.test.cjs`。5 项测试全部通过，覆盖牌型边界、炸弹大小、首手限制、非法操作不改变状态、不要后重新接牌、出完牌后的领出衔接，以及 250 局带种子的完整对局（包含随机合法出牌和主动不要），检查牌数守恒、名次唯一及正常终局。

内置浏览器通过本地 HTTP 服务实际验证：首手限制提示、提示选牌与出牌、电脑跟牌、整局游玩至三人名次确定、再来一局、暂停、规则弹层、重开、记录刷新保留、大厅搜索进入与返回语言保留。控制台未见警告或错误。

实测 CSS 视口：320×568、360×640、390×844、568×320、844×390、768×1024、1024×768、1280×720、1920×1080。完整 18 张手牌、导航和主要操作均在一屏，页面无横向或纵向溢出；对小竖屏、短横屏和桌面进行了截图目视检查。八国语言均检查了 320×568 的标题、操作区及返回链接。

检查了八国语言键和占位符一致性、脚本语法、本地资源路径、大厅唯一登记及字体覆盖。大厅字体以原版 TTF 更新，保留原子集已有字形，并同步字体 URL 版本。

验证限制：内置浏览器禁止 `file://` 导航，因此直接双击模式仅通过普通脚本、相对路径、无 fetch/模块依赖等静态检查；未在实体触屏设备或其他浏览器引擎实测，也未实测系统语言自动检测与跨标签页语言同步。相关行为沿用项目现有语言模块。未提交或发布。
