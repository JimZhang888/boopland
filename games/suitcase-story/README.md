# 行李箱收纳师

入口：`index.html`。已在根目录 `gamelist.js` 登记，分类为「解谜」。

纸张、铅笔描边与低饱和手绘小物组成的静态收纳游戏。六个旅行主题：海边、森林、巴黎、雪山、沙漠、京都；箱子从 6×5 格逐步增加至 7×7 格，共 60 件物品。每关都有经过验证的完整拼合解，允许任意有效的摆法。

## 操作

- 拖动物品到箱内，或先点物品再点格子（该格为外接矩形的左上角）。桌面鼠标和触摸 Pointer Events 均可用。
- 点击「旋转」或按 R；绿色虚线和 ✓ 表示可放，× 表示重叠或越界。
- 已装入的物品可以重新移动，或点击「取出」放回清单。拖回清单也可以取出。
- 方向键移动预览，Enter 放下，Escape 取消，Delete / Backspace 取出，Ctrl / ⌘ + Z 撤销。
- 提示会优先寻找兼容当前摆法的解。搜索受节点预算限制；找不到时建议取出一个需要调整的物品。提示不会自动修改玩家的摆法。
- 撤销可恢复最近 100 步，包括取出和整箱重置。没有倒计时或失败惩罚。
- 装满后点击「合上行李箱」领取印章，再去下一站。旅行手帐可随时选择任意主题。

进度、每关摆法、已获得印章和音效设置保存于本机 `boopland-suitcase-story-v1`。刷新可恢复，存储不可用时仍可游玩。音效默认关闭，点击音符启用；隐藏页面会暂停声音并取消拖动。

## 文件与接入

普通 HTML/CSS/JS，无构建、依赖安装、CDN 或数据请求；资源均为相对路径，可通过 `file://` 或静态服务器访问，也支持网站子目录。物件与封面为本目录内的原创 SVG，未使用参考游戏的素材。

- `engine.js`：关卡、旋转、碰撞、撤销及提示求解。
- `game.js`：鼠标、触摸、键盘、存储和界面状态。
- `art.js`、`cover.svg`、`paper.svg`：物件、旅行插画、封面和纸纹。
- `translations.js`：全站八国语言文案，使用根目录 `i18n.js`。
- `verify.cjs`：运行 `node games/suitcase-story/verify.cjs`，验证关卡可解性、物件连通性、碰撞、撤销、存储校验、翻译、资源和大厅登记。
