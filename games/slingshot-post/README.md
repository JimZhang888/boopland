# 弹弓快递

拉动弹弓，把包裹送进乡间邮箱。纸张与铅笔线稿风格，8 站渐进路线，包含反弹、顺逆风、按钮闸门、升降障碍和移动邮箱。

在大厅 `games.html` 搜索「弹弓快递」即可进入，也可直接打开本目录的 `index.html`。使用原生 HTML、CSS、JavaScript、Canvas 和独立 SVG 封面；资源均为相对路径，不需要构建、第三方依赖或联网素材。共用项目八国语言与统计加载器。

## 操作

- 鼠标或手指按住左侧弹弓上的包裹，向左下方拉，松开后发射。拖得越远，力度越大。画布之外不屏蔽触摸手势。
- 也可使用「角度」「力度」滑条与「寄出包裹」按钮。键盘左右调角度、上下调力度，空格发射；原生滑条聚焦时遵循滑条自身的方向键操作。
- P / Esc 暂停或继续，R 重开本站；拖拽时 Esc 取消，不消耗包裹。
- 每站 3 个包裹。第 1、2、3 投送达分别获得 3、2、1 枚邮票；成功后解锁下一站。地图可重玩已经解锁的关卡，保留最佳记录。
- 有反弹要求时，必须先碰绿色弹跳板；有按钮要求时，先碰圆形按钮打开闸门。墙壁也能反弹，但不替代弹跳板任务。每一投会重置按钮和反弹条件。
- 短点线预测接下来的一段轨迹，淡色实线保留上一投。风会持续影响飞行；升降门和移动邮箱需要配合发射时机。
- 切换标签页、窗口失焦、打开说明或地图时暂停。手动暂停和离开页面后需要主动继续；关闭说明/地图恢复此前状态。
- 音效默认关闭，可用顶部音符按钮开启；由浏览器合成，无外部音频。

## 结构与保存

- `engine.js`：固定 1/120 秒物理步长、8 关数据、碰撞与投递判定、独立瞄准模拟、存档校验。可以直接由 Node 加载测试。
- `scene.js`：Canvas 手绘场景、包裹、机关、轨迹和粒子；画布按容器宽高完整容纳，最高 2 倍设备像素比。
- `game.js`：指针/键盘输入、暂停、对话框、音效、语言刷新和存档。
- `translations.js`：中文、英文、日文、韩文、法文、德文、西班牙文、巴西葡萄牙文；游戏内不另设语言选择器。
- 存储键为 `boopland-slingshot-post-v1`，保存各站最佳邮票与当前站，解锁进度由完成记录推导。存储不可用时继续正常游玩，并显示本次访问暂存提示。刷新恢复所在站与最佳记录，不恢复半途飞行。

## 验证

在项目根目录运行：

```sh
node --test games/slingshot-post/engine.test.cjs
```

13 项规则测试通过：全部关卡可通关、移动机关不同初始时刻可通关、无效与重复发射、三次失败和重开、三档邮票评分、暂停与不同帧率一致性、顺逆风方向、机关重置与未满足任务拒收、弹跳板及高速薄闸门碰撞、瞄准不改变实局、损坏存档恢复、八国语言键和占位符完整性、大厅登记及本地资源路径。

通过内置浏览器的 HTTP 静态预览实测：

- 8 站完整投递、解锁和最终 24 枚邮票结算；包含真实拖拽反弹、顺逆风、按钮开门、升降门、移动邮箱和最终组合机关。
- 空格发射、滑条方向键调整、飞行途中暂停和恢复、三次失败与重试、音效开关反馈、地图选关、说明弹层、刷新保留最佳邮票。
- 大厅搜索找到唯一「弹弓快递」卡片，进入与返回大厅保留语言参数。
- 中文准备界面：320 × 568、360 × 640、390 × 844、568 × 320、844 × 390、768 × 1024、1024 × 768、1280 × 720、1920 × 1080；页面无横纵溢出，主要操作均在视口内。
- 八国语言均检查 320 × 568 和 568 × 320；标题不挤占工具区，主要控件可达。中文 320 × 568 成功结算的两个按钮完整显示，结算层无需滚动。
- 已检查脚本语法、资源路径与浏览器错误日志，未发现脚本错误。

验证限制：未使用实体触摸设备或人工听音；`file://` 双击方式仅通过普通脚本、相对路径和无网络加载依赖检查，未直接在浏览器实测。暂停定时边界、损坏存档和移动机关多初始时刻由规则测试覆盖。
