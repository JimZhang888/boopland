# 昨天的我 · Yesterday, Me

录下这一遍的移动、跳跃与搬箱动作，回到起点后，过去的自己会重放这些行为。把等待留给分身，让现在的自己继续向前。

入口：`index.html`。已登记到根目录 `gamelist.js` 的「解谜」分类，带原创 SVG 封面。沿用项目的米白纸张、铅笔线稿与低饱和配色。原生 HTML / CSS / JavaScript，无安装、构建、模块加载、CDN、后端或资源请求依赖；按项目约定引入公共 `i18n.js` 和 `analytics.js`。

## 操作

| 操作 | 键盘 | 触屏 / 鼠标 |
| --- | --- | --- |
| 左右移动 | ← → / A D | 按住方向按钮 |
| 跳跃 | Space / W / ↑ | 跳跃按钮，可与方向按钮同时按住 |
| 搬起 / 放下箱子 | E | 搬 / 放按钮 |
| 留下本次分身并回到起点 | R | 留下分身 · 重来 |
| 重走这一遍，保留已有分身 | T | 重走这一遍 |
| 撤回最近一个分身 | Backspace | 撤回分身 |
| 暂停 / 恢复 | P / Esc；弹窗内 Esc 关闭 | 顶部暂停 / 继续 |
| 原地开始记录与重放 | Enter | 轻点方向按钮即可开始 |

- 每遍从第一次输入开始计时，最长 30 秒，最多留下两个分身。录满后暂停，玩家选择保存这段分身或重试，不会自动覆盖旧录制。
- 回溯会重置角色、箱子、门与平台，已有分身从同一起点按原节奏行动。分身完成录制后停止输入，继续遵守重力和碰撞，站定后可以一直压住开关、托住桥台或举着箱子。
- 箱子属于共享场景，同一时刻只能由一个角色持有；分身也能拾取和放下箱子。◇ 机关只接受落地的箱子，人物不能代替。
- 桥下的字母托举点会自动触发举手动作；达到要求的支撑数量后，悬空桥台下降到可以跳跃通过的高度。桥台可以承载角色，支撑离开时回升。
- 普通重试保留分身；撤回只删除最新一个；重置本关会清除全部分身并先提示确认。六关均可通过顶部关卡菜单自由选择。
- 切换窗口或标签会暂停，回到页面后点击继续。调整窗口尺寸不重置本局。

## 六页时间手记

| 关卡 | 核心内容 |
| --- | --- |
| 替我留一扇门 | 一位分身踩 A，当前角色穿门 |
| 两份小小的等待 | 两位分身分别踩 A、B，同步打开出口 |
| 把箱子交给昨天 | 第一位分身开门；第二位搬箱压 B，再回到 C；当前角色通关 |
| 接住一座小桥 | 一位分身在谷底托桥，当前角色跳到右岸 |
| 我们撑起的路 | 两位分身一起托住桥台，第三遍通过 |
| 送给未来的自己 | 分别留人开门、托桥，自己把箱子送过河压住出口机关 |

每关都有可展开的具体提示。通关后提供用时、分身数量、下一关与重玩；六关全部完成显示总完成页。

## 实现

- `engine.js`：独立于 DOM 的 60 Hz 固定步长模拟，包含六关数据、逐帧输入录制、双分身同步重放、人物移动与跳跃、箱子归属、机关与门、承载角色的桥台。记录的是输入，不会用位置瞬移替代合作中的物理互动。
- `scene.js`：按容器宽高完整容纳的 Canvas 绘制，像素比最高为 2；原创小纸人、围巾、双色分身、手绘地形、机关线路、桥台、云朵和纸门。遵循减少动态效果设置。
- `game.js`：键盘与多指 Pointer Events、输入短按缓存、暂停、选择关卡、帮助、结算、计时与录制条。只保存当前关卡和已通关编号，不保存尚未完成的录制。
- `translations.js`：接入全站语言接口，提供中、英、日、韩、法、德、西、巴西葡语共八套完整文案，覆盖动态状态、Canvas 标签、提示、说明和无障碍标签。游戏不添加单独语言选择器，返回大厅保留 `lang`。
- 存储键：`boopland-yesterday-me-v1`。读取时验证关卡与完成记录；异常存档、存储权限不可用时仍能游玩。
- 大厅字体子集已补齐新增文案，并同步更新缓存版本参数。
