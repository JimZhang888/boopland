# 五子棋

15×15 无禁手五子棋，人机对弈。黑棋先手，横、竖或斜向连续五子及以上获胜；棋盘落满且无人获胜时和棋。

## 操作

- 点击或触摸交叉点落子；键盘方向键移动焦点，Enter 或空格落子。
- AI 分为简单、正常、难。默认正常难度、玩家执黑。
- 简单采用带随机性的局部棋形评分，偶尔错过防守；正常优先取胜、堵四，并综合攻守棋形；难档使用限时迭代加深的 Alpha-Beta 搜索，最多四层，强制防守分支最多延伸至八层。
- 难档默认搜索预算为 850 毫秒，定期让出主线程；可以在 AI 思考中悔棋或重开。时间预算不是棋力等级承诺，低性能设备可能完成较浅的搜索。
- 悔棋撤销玩家最近的一手和 AI 的应手；执白时保留 AI 的首子。对局结束后也可悔棋。
- 对局中更改难度或棋色会标注为下一局设置，当前对局保持原设置。点击“新的一局”并确认后生效。
- 切换标签页时取消未完成搜索，返回时重新计算 AI 应手；切换语言或窗口尺寸不重置棋盘。

## 运行

从根目录 `games.html` 进入，或直接打开本目录 `index.html`。纯静态、相对路径，无外部库、构建步骤、fetch 或模块加载。沿用全站八国语言与统计加载器。

```powershell
node --test games/gomoku/engine.test.cjs
```
