# 六角小田园 / Hex Meadow

原创的六角地块拼接小游戏，玩法灵感来自 [Dorfromantik](https://www.toukana.com/dorfromantik)。用纸张、铅笔细线和低饱和的原创 SVG 小景，拼接森林、村庄、河流与麦田。

## 运行

- 从大厅「策略」分类进入，或搜索「六角小田园」。
- 独立入口：`games/hex-meadow/index.html`。
- 原生 HTML / CSS / JavaScript，普通脚本和相对路径，无构建、后端、CDN、外部素材或安装依赖。
- 语言沿用全站 `i18n.js`，提供中文、英文、日文、韩文、法文、德文、西班牙文及巴西葡萄牙文；返回大厅保留语言。

## 游玩

1. 点击虚线空地预览。用左右旋转按钮或 Q / E / R 调整朝向，再点击「放在这里」。选中地图后，方向键可选择空地，Enter 放置，Esc 取消选择。
2. 放置得 10 分，每条相同地形的邻边再得 10 分；至少 3 个邻居且邻边全部吻合，额外获得 30 分和 1 块地。
3. 森林、村庄、河流必须通过同类边连接才计为同一区域。任务追踪各类最大连通区域，初始目标分别为 4 / 3 / 3。每达成一个目标获得 100 分和 5 块地，下一目标增加 3。
4. 河口只能接河口，不能接陆地；其他地形允许不匹配，只是不获得该边的匹配分。
5. 田园旅程从 36 块地开始，用尽后结算；自由造景不消耗地块。每局可换牌 3 次，支持连续撤回，连同牌序、奖励和任务一起恢复。
6. 拖动平移地图，滚轮或双指缩放，使用 − / + 按钮也可缩放，⌖ 恢复全景。小屏可以放大后拖动查看。
7. 新田园按钮提供模式选择，说明与结算使用可关闭的弹窗。音效默认关闭，可主动开启；后台暂停声音和装饰动画，支持减少动态效果设置。

## 保存与边界

- `boopland-hex-meadow-v1` 保存种子、模式、合法操作序列与当前朝向；恢复时按规则回放，拒绝损坏或不合法的数据。分数纪录使用 `boopland-hex-meadow-best`。
- 存储不可用时仍可游玩，并显示未保存提示。存档随浏览器和访问源隔离。
- 无倒计时。单页最多记录 2,000 次操作，达到后可欣赏风景、撤回或开启新田园。
