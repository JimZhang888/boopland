# 纸上地铁 / Paper Metro

用彩色铅笔连接车站，调配列车，在不断生长的城市里疏导客流。玩法参考 [Mini Metro](https://dinopoloclub.com/games/mini-metro/) 的线路规划与运力分配；本目录的界面、地图、封面、代码均为独立实现，不使用原作素材。

## 入口与运行

- 大厅 `../../games.html` →「策略」，或搜索「纸上地铁」。
- 独立入口 `index.html`，支持直接双击和普通静态服务器，支持部署到子目录。
- 原生 HTML、CSS、JavaScript、SVG，无运行依赖、构建步骤、远程素材或后端。
- 引入全站 `../../i18n.js` 与 `../../analytics.js`；八国语言随欢迎页设置，返回链接保留语言，不另设语言切换器。

## 玩法

1. 开始时有 5 个车站、3 条可用线路、3 列车。选择 A / B / C 彩笔，从车站拖过另一站并松手；也可逐站点击，最后点「完成」。有效线路至少有两站，不重复经过同一站。
2. 新线路会自动获得一列空闲列车。用 + / − 增减当前线路列车，每线最多 5 列；没有列车的线路显示虚线，不参与乘客寻路。
3. 候车小图形表示目的地形状。列车自动往返，送到任意相同形状的车站计分；共用车站的线路之间可自动换乘。乘客按正在运营的网络寻找最短路径，不登上无法到达目的地的列车。
4. 从线路任一端点继续画可延长；「重画线路」重新选站，「收回线路」释放其列车。画线时暂停时间，完成才应用，取消保留原线。手势被取消时恢复手势前的草稿。改线和撤车时，车上乘客回到上一站，不会直接消失。
5. 每 60 秒进入新的一周：获得 1 列车，并任选额外 1 列车、解锁 1 条线路（最多 5 条）、所有列车增加 2 个座位。初始每列 6 个座位。补给选择期间暂停。
6. 第一座新站在 22 秒后开放，随后约每 23 秒增加一站，最多 18 站；陆续出现菱形和星形目的地。客流持续增长。
7. 单站候车达到 9 人时累积拥堵压力，连续 18 秒会结束运营；降至 9 人以下，压力以两倍速度恢复。拥堵有轮廓倒计时环、状态文字提示，不单靠颜色表示。
8. 「悠闲画线」模式不会因拥堵失败，单站达到 24 位候车乘客时暂停为该站生成新客流；已生成的乘客不会被删除。两种模式分别保存最佳送达人数，不保存整局进度。存储不可用时仍可正常游玩。

车站在小屏后期采用紧凑显示：旁边的数字是候车总人数，下方小图形表示当前候车者需要的目的地种类。站点会在原地理位置附近适度避让，便于触摸选择；地图内所有车站始终可见。

## 操作与状态

- 鼠标、触屏：拖动绘线，或逐站点击后完成。画线期间「↶」撤销最后一站。
- 键盘：Tab 聚焦控件和车站，车站上 Enter / 空格选择；焦点不在按钮或车站上时，空格暂停、1–5 选择线路、Enter 完成。Esc 取消绘线，Backspace 撤销一站。
- 暂停后仍可调整线路、列车；支持 1× / 2× 运行。
- 玩法说明、每周补给、重开确认、结算使用弹窗。手机短屏的长说明可在弹窗内滚动。
- 页面隐藏时自动暂停，返回后由玩家继续，避免后台突然失败。
- 旋转或调整窗口保留本局状态；地图使用容器尺寸绘制，指针坐标与 SVG 同步。静止时不重复绘制列车。

## 文件

- `engine.js`：确定性随机、客流、列车、最短路径、换乘、拥堵和补给，无 DOM 依赖。
- `game.js`：SVG 地图、编辑草稿、指针/键盘输入、弹窗、存储与自适应布局。
- `translations.js`：八种语言、每种 79 个文案键，运行时检查完整性。
- `style.css`：纸张、手绘线稿及横竖屏布局。
- `cover.svg`：原创大厅封面。
- `engine.test.cjs`：原生 Node.js 测试，无第三方依赖。
