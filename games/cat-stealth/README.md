# 猫咪潜行

原生 HTML / CSS / JavaScript 的俯视角潜行小游戏。暖白纸张、铅笔线稿和低饱和配色，Canvas 场景与 SVG 封面均为本游戏独立绘制。无需下载素材、构建或安装运行依赖。

从项目根目录 `games.html` 搜索「猫咪潜行」，或直接打开本目录 `index.html`。相对路径兼容静态服务器、子目录部署和本地文件；使用全站八国语言及统计加载器，返回大厅保留语言参数。

## 玩法

- 三关依次解锁：午后的小鱼铺、后院的储藏室、最后一班巡逻。分别有 1 / 2 / 3 名守卫，以及 3 / 4 / 5 份小鱼干。
- WASD、方向键、按住屏幕箭头移动；点击地面会沿可通行的格子自动寻路。靠近小鱼干自动拾取，收齐后回到绿色脚印处撤离。
- 守卫有固定巡逻路线和可见视野。货架遮挡视线；进入视野持续约 1.25 秒会被抓。警觉超过一定阈值会追踪小猫，丢失目标后调查，再恢复巡逻。
- 在纸箱约一格以内，按 E 或「躲进纸箱」隐藏，再按一次出来。藏好时无法移动，不会被发现，警觉逐渐下降。
- 按 Q 或「扔纸团」进入瞄准，再点击虚线圈内的空地。每关 4 个纸团，投掷范围 240 地图像素、冷却 2.5 秒；不能穿过货架。附近 290 像素内尚未进入强警戒的守卫会走向落点、搜索 3.5 秒，再返回巡逻。纸箱内也能投掷。
- 过关获得一星；全程未触发警报加一星；在本关 100 / 135 / 170 秒内完成再加一星。最佳星数、最快用时、解锁进度存于 `boopland-cat-stealth-v1`，存储不可用时仍可继续当前会话。
- P / Esc 或顶部按钮暂停；瞄准时 Esc 先取消瞄准。失焦、切换标签页、打开说明会暂停；主动继续后恢复。暂停菜单提供选关和重开，手机也可访问。
- 音效默认关闭，用户点击开启后用 Web Audio 合成。暂停时停止帧循环；单次模拟最多推进 50 毫秒，避免卡顿或恢复页面后突然被抓。支持减少动态效果偏好。

## 验证

在项目根目录运行：

```sh
node --test games/cat-stealth/engine.test.cjs
```

14 项测试覆盖全部地图的可达性、逐格自动寻路与碰撞、方向速度、遮挡与视野范围、声响诱敌及边界落点、纸箱隐藏、被抓与暂停、长时间巡逻、拾鱼撤离、三关带真实巡逻的完整通关、存档清洗、八国语言键名与占位符、卡片登记及资源路径。

内置浏览器的 HTTP 预览检查：

- 中文布局检查：320 × 568、360 × 640、390 × 844、568 × 320、844 × 390、768 × 1024、1024 × 768、1280 × 720、1920 × 1080。页面无横纵溢出，主操作在视口内。
- 八种语言分别检查 320 × 568、568 × 320，返回入口与标题不重叠，主操作未溢出。
- 实际操作：开始、点地面自动移动、纸箱躲藏、瞄准投掷、P 快捷键暂停和继续、说明关闭、路线开关、重开及音效开关。
- 浏览器实际完成第一关：收齐 3 份小鱼干并返回入口，44 秒、零警报、三星；第二关解锁，刷新后仍保留解锁和三星记录。通关截图位于项目 `.artifacts/cat-stealth-victory.jpg`。
- 大厅搜索得到唯一卡片，进入、返回均保留 `lang=zh-CN`；页面控制台未见脚本错误。

限制：其余两关完整通关、失败及存档异常边界由自动测试覆盖；未使用实体触摸设备或人工听音。直接双击方式已检查相对路径和无模块 / fetch 依赖，未在 `file://` 浏览器环境实测。
