# 割绳子

在纸张与铅笔画成的糖果花园里，划断绳子、收集星星，把糖果送进小兔子的嘴里。12 关逐步加入双绳、摆荡、三绳、尖刺、上升泡泡、风和移动尖刺。

从根目录的 `games.html` 搜索「割绳子」进入，也可以直接双击本目录的 `index.html`。纯静态 HTML、CSS、JavaScript 与 Canvas，不需要构建、依赖安装或联网素材。共用项目八国语言与访问统计加载器，返回大厅保留语言设置。

## 操作

- 用鼠标或手指按住并划过绳子，也可轻点绳子，或点击右侧／底部的编号按钮。
- 点击「开始这一关」启动摆荡；直接剪绳也会启动。
- 键盘 `1` / `2` / `3` 剪对应编号的绳子，`B` 戳破泡泡，空格 / `P` 暂停或继续，`R` 重玩。按钮聚焦时空格仍激活该按钮。
- 泡泡带糖果向上飞，点泡泡或「戳破泡泡」按钮让糖果重新落下。必须戳破泡泡才能喂给兔子。
- 糖果进嘴即过关，不要求集齐星星；每关可收集 3 颗星星。过关解锁下一关，关卡手记可以重玩已解锁关卡。
- `Esc` 暂停或关闭说明／选关弹层。切换标签页、窗口失焦时自动暂停，返回后手动继续。打开弹层暂时停止物理，关闭后恢复此前的暂停状态。
- 音效默认关闭，通过音符按钮开启；音效由浏览器合成，没有外部音频。

## 文件与保存

- `engine.js`：12 关数据、固定 1/120 秒步长的绳长约束物理、划线命中、星星、泡泡、碰撞、通关和存档校验，可直接由 Node 加载。
- `scene.js`：纸面花园、铅笔绳子、糖果、小兔子及粒子。画布完整容纳在可用区域，最高 2 倍设备像素比；尺寸变化不重置游戏。
- `game.js`：鼠标、触摸和键盘输入、暂停、弹层、音效、语言刷新及本地记录。
- `translations.js`：中文、英文、日文、韩文、法文、德文、西班牙文、巴西葡萄牙文；游戏内不另设语言切换器。
- `cover.svg`：独立手绘封面，已登记到根目录 `gamelist.js` 的「益智」分类。
- 存储键 `boopland-cut-the-rope-v1` 保存当前关、最佳星级及音效设置。刷新后从所在关重新准备，不恢复半途物理状态。无法使用本地存储时继续正常游戏，并提示只保留本次访问的进度。

## 验证

项目根目录运行：

```sh
node --test games/cut-the-rope/engine.test.cjs
```

10 项测试覆盖：全部 12 关的三星解、划线和轻点剪绳、重复与暂停输入、固定步长一致性、绳长和摆荡动量、泡泡与喂食条件、尖刺和越界失败、零星通关与损坏存档、八国语言键与占位符、大厅记录与资源路径。

Chrome 无头浏览器实测（物理过程使用可控动画帧，操作通过浏览器输入事件）：

- 鼠标划线和模拟触摸划线完成第一关，键盘操作完成其余 11 关，共 36 星；刷新保持当前关与最佳记录。
- 暂停／继续、重玩、音效开关、失败与重试、自动暂停、说明、选关，以及保留弹层打开前的暂停状态。
- 9 种视口：320 × 568、360 × 640、390 × 844、568 × 320、844 × 390、768 × 1024、1024 × 768、1280 × 720、1920 × 1080。
- 八国语言在 320 × 568、568 × 320 的普通关和双绳泡泡关均检查无页面溢出，必要控件没有裁切；小屏结算、说明和选关弹层可操作。
- 大厅搜索找到唯一卡片，进入和返回保留语言，支持网站子目录部署；`file://` 直接打开并游玩成功。
- 浏览器禁止本地存储时仍能通关，并显示临时保存提示。未发现脚本异常或资源加载失败。

验证限制：未使用实体触屏设备或人工听音；触摸使用浏览器模拟，未单独实测 Safari / Firefox。
