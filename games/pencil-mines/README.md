# 铅笔扫雷

Boopland 的纸张铅笔风扫雷。原生 HTML、CSS、JavaScript，普通脚本与相对路径，无构建步骤、第三方库、图片 CDN 或游戏后端。

## 入口与玩法

在项目根目录的 `games.html` 搜索「铅笔扫雷」，或直接在浏览器打开本目录的 `index.html`。通过页面左上角返回大厅，链接会保留全站语言。

- 随手一页：8 × 8，10 颗雷。
- 认真一点：10 × 10，18 颗雷。
- 推理时刻：12 × 12，28 颗雷。
- 翻开所有安全格即获胜，无需手动标出所有地雷；踩雷后可查看完整棋盘，错误旗帜用叉号标出。
- 首次翻开的格子及其周围八格一定安全，空白连通区域自动展开。随机棋盘不保证无需猜测。
- 右键、触摸长按 420 毫秒，或选择「插旗」后点击，可标记或取消标记。移动超过 12 像素会取消长按，长按后的点击不会误翻格。
- 在「翻开」模式下，点击已经打开的数字，周围旗数与数字一致时会连开其余邻格；标错旗仍会踩雷。
- 键盘方向键移动焦点，Enter / 空格使用当前工具，F 标记当前格，P / Esc 暂停或继续，Home / End 移到本行两端。
- 首次翻开后开始计时；暂停、说明、重开确认期间停止。切换标签页后保持暂停，需主动继续。正在进行的游戏重开或切换难度需要确认。
- 三档最佳用时分别保存在本浏览器的 `boopland-pencil-mines-best-v1-<level>`；存储不可用时仍可游玩。本局进度不持久化。
- 共用根目录 `i18n.js` 的八国语言；语言入口仅在欢迎页，语言变化只更新文案，不清空棋盘。遵循系统的减少动态效果设置。

## 文件

- `index.html`、`style.css`：响应式页面、内嵌手绘 SVG 图形与弹窗。
- `engine.js`：独立规则引擎，负责安全布雷、展开、标记、连开和胜负。
- `game.js`：鼠标、触摸、键盘、计时、纪录与页面状态。
- `translations.js`：八国语言静态文案、动态消息及无障碍标签。
- `cover.svg`、`favicon.svg`：本目录独立矢量素材。
- `engine.test.cjs`、`runtime.test.cjs`：无需安装依赖的规则与控制器测试。

## 验证

在项目根目录运行：

```text
node --test games/pencil-mines/engine.test.cjs games/pencil-mines/runtime.test.cjs
```

13 项测试通过。包含三档难度所有首击位置的 1,540 个随机棋盘、安全邻域与独立邻雷计数校验、空白展开、标旗上限、正确与错误连开、胜负终态锁定、重开、非法输入、随机种子复现，以及翻译键与插值一致性、资源路径和唯一大厅登记。

控制器测试使用 DOM 和时钟替身，验证计时起点、暂停和弹窗冻结、隐藏页面后需主动继续、长按只插旗一次并抑制随后点击、移动与取消触摸、重开清理残留长按、难度切换确认、语言切换保留进度，以及存储被禁用时继续游玩。

内置浏览器实际操作验证：右键插旗/取消、旗帜防误翻、首击与空白展开、插旗工具、键盘标旗/方向移动、暂停/继续、说明弹窗、重开取消、失败结算、完整一局通关、查看终局、刷新后保留最佳纪录、欢迎页切换语言同步到进行中的游戏、大厅搜索与进入/返回路径。浏览器未报告脚本错误。

以下 CSS 视口检查了最高难度的完整棋盘与主要操作，均无页面横向或纵向溢出：320×568、360×640、390×844、568×320、844×390、768×1024、1024×768、1280×720、1920×1080。八国语言额外检查了 320×568 与 568×320，长文案不会遮挡主要按钮。极小窗口与文字放大允许受控滚动，长说明在弹层内部滚动。

验证限制：未使用真实手机触屏硬件；长按通过控制器事件模拟验证。直接双击的 `file://` 方式仅检查了相对资源、普通脚本和存储异常兼容性，浏览器实测使用本地静态 HTTP 服务。

本游戏放在 `games/pencil-mines/`，并在根目录 `gamelist.js` 登记。
