# 反着来

入口为 `index.html`，已登记到根目录 `gamelist.js`。游戏使用普通脚本、相对路径和本地资源，不需要安装依赖或构建。

- 方向反转：上、下互换，左、右互换；方向键 / WASD 或点击按钮。
- 颜色对调：红、蓝互换，黄、绿互换；数字键 1–4 或点击按钮。
- 混合模式随机切换方向与颜色。
- 每局 60 秒，答错或单题超时扣一次机会，3 次后结束。
- 连续答对每 5 题提高倍率，最高 ×4；每答对 5 题缩短单题限时，最低 1.3 秒。
- Esc / P 暂停，切换窗口自动暂停。各模式最高分和音效设置保存在本机。
- 使用根目录 `i18n.js` 的八国语言，语言切换入口位于欢迎页；切换语言不会重置本局。
