# 纸间节拍

纯静态的双轨节奏小游戏，入口为 `index.html`，已登记到根目录 `gamelist.js` 的休闲分类。无需安装依赖或构建，不加载远程字体、音乐或图片。

## 玩法

- 左轨敲桌：A / F / 左方向键；右轨拍手：J / L / 右方向键。也支持鼠标和触摸按钮，长音需要保持按住。
- 音符中心到达铅笔线时击拍。每首包含 64 个音符，按「找到节拍 → 长音 → 左右交替 → 混合合奏」四段推进。
- 三种曲目速度：午后随想 84 BPM、窗边小雨 104 BPM、月光散步 120 BPM，分别约 69、55、48 秒，另有四拍预备。
- 判定窗口为 ±160ms，±70ms 内为精准。精准 100 分、普通命中 65 分，完成长音额外 50 分；每 10 连击提高后续音符倍率，最高 ×4。
- 漏拍、提前松开和空拍打断连击；失误不会提前结束本曲。准确率计入空拍，结算展示评级、判定统计、最大连击和全连奖励提示。
- P / Esc 或右上角按钮暂停；窗口失焦及页面隐藏时自动暂停。继续前有三拍准备，长音可在恢复后的 0.8 秒内重新按住。
- 使用 Web Audio 合成旋律、和弦、节拍和击拍音效，由开始或声音按钮的用户操作解锁。声音不可用时可继续跟随可视谱面游玩。
- 各曲最佳得分、曲目和声音偏好保存在本机，存储不可用时仍可游玩。语言沿用全站设置，包含八国语言；返回大厅保留语言参数。

## 文件

- `engine.js`：独立谱面、判定、连击与分数逻辑，可在 Node 中测试。
- `game.js`：输入、音频调度、Canvas 绘制、暂停及界面。
- `translations.js`：63 个界面和动态文案键，完整覆盖八种语言。
- `style.css`、`cover.svg`：纸张与铅笔风格，自带矢量封面。
