# 桌面漂移

纯静态 Canvas 玩具车计时游戏，入口 `index.html`，已登记到大厅的「动作」分类。无需安装、构建或后端；所有素材都在本目录。页面引入项目共用的语言和访问统计脚本，支持八国语言。

## 操作

- 自动油门，`← / →` 或 `A / D` 左右转向。
- 弯前按住 `Space` 同时转向，增加转向能力并降低侧向抓地；松开后恢复抓地。
- `R` 立即重试，`P` 或 `Esc` 暂停 / 继续。
- 屏幕按钮支持 Pointer Events、多指方向与漂移组合、取消与失焦释放。
- 音效默认关闭，由右上角按钮开启。失焦或切换标签页会暂停，返回后手动继续。

## 玩法和实现

一条手绘课桌赛道，依次经过尺边直道、笔筒回弯和橡皮擦弯。目标圈长约 20–30 秒；无失误的确定性驾驶测试为 20.31 秒。转向采用平滑输入，车身朝向与速度方向分开计算；漂移有轮胎印，碰撞有回弹、减速、碎屑和轻微震动（遵循减少动态效果设置）。

每圈使用有方向的净进度和三个顺序检查点，倒车跨过起点不会误判完赛。物理固定 120 Hz，分段越线时间插值。超过三分钟可重新挑战。重试使用相同的滚动起跑速度，不插入倒计时。

最佳圈保存到 `boopland-desk-drift-best-v1`，包含轨迹、时间、分段、碰撞次数和漂移时长。轨迹约 30 Hz 采样，以时间插值播放蓝色无碰撞幽灵；实时差距比较同一赛道进度的到达时间。结算逐段比较该圈与起跑时的最佳圈，并指出收益或损失最大的分段。存储不可用时继续在当前页面保留最佳圈；版本不匹配或损坏的存档会被忽略。

## 验证

```powershell
node --test games/desk-drift/engine.test.cjs
```

11 项测试覆盖完整驾驶计圈、60/120/144 Hz 一致性、漂移物理、边界反馈、旋转文具碰撞、倒车防误计圈、终止状态、幽灵回放、异常存档、八国语言和大厅资源路径。

内置浏览器通过 HTTP 实测：初次完赛、分段结算、重试、暂停、刷新读取最佳圈、较慢圈不覆盖最佳、存储被禁用时继续游玩、搜索进入和返回大厅保持语言。完赛流程使用临时自动驾驶夹具并隔离测试存档，交付文件不包含自动驾驶或调试入口。测试场景中一次碰撞使第一段慢了 0.69 秒，结算正确显示对应分段损失。

响应式检查覆盖 `320×568`、`360×640`、`390×844`、`568×320`、`844×390`、`768×1024`、`1024×768`、`1280×720`、`1920×1080`，游戏页无页面溢出；八国语言在 `320×568` 检查了文字和按钮边界。竖向剩余空间足够时，赛道旋转显示；短横屏把方向与漂移按钮移到右侧。帮助及极短屏结算允许在弹层内滚动。

验证限制：内置浏览器安全策略不允许 `file://`，双击打开仅做相对路径和资源完整性检查，没有浏览器实测。尚未在实体手机上验证多指触控与音频输出。
