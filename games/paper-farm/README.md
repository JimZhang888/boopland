# 纸上农场 / Paper Farm

以《疯狂农场》的种养、加工和订单经营循环为灵感，原创实现的轻松农场小游戏。米白纸张、铅笔线稿、低饱和田园配色，独立 SVG 地景、作物、动物、设备与封面。没有倒计时失败、作物枯萎或动物死亡。

## 运行与接入

- 大厅 `games.html` 的「休闲」分类已登记，可以搜索「纸上农场」。
- 独立入口为 `games/paper-farm/index.html`，纯 HTML/CSS/JavaScript、相对路径、普通脚本，无构建、后端、CDN、远程素材或运行依赖。
- 共用根目录 `i18n.js` 的八国语言与 `analytics.js`。返回大厅保留语言，仅欢迎页提供语言切换。

## 游玩

1. 从 100 金币、3 块农田、2 份小麦开始。选种子后点击空地播种，再点幼苗浇水，剩余生长时间缩短 40%，每次种植只能浇水一次。成熟后点击收获，也可一键收获全部成熟作物。
2. 3 种作物：小麦、胡萝卜、草莓。每块田收获 3 份，小麦种子永久免费，金币用完也能继续游玩。
3. 点击虚线土地并确认开垦，最多 9 块田。开垦从 25 金币开始，每增加一块，下一块贵 15 金币。
4. 购买母鸡或奶牛，用小麦喂养，产出鸡蛋和牛奶。生产结束后手动收取，未收取的产品不会消失。
5. 建造磨坊、面包窑、果酱锅。配方分别为 2 小麦→1 面粉、1 面粉+1 鸡蛋→1 面包、2 草莓→1 果酱。每台设备同时加工一批；原料只在手动开始时消耗。
6. 集市按件出售换取金币；邻里订单按完整配方交付，奖励更高。每 2 张订单提升一级，逐步解锁新作物、动物和设备。完成 8 张成长订单达到 5 级，显示庆祝弹窗，之后订单循环，可继续自由经营。
7. 所有主要操作支持按钮、鼠标与键盘；Tab/Enter 访问按钮，1–4 切换面板，P 暂停。帮助中提供重新开农场入口，清空进度前有确认。

## 存档与时间

- `boopland-paper-farm-v1` 保存金币、订单、库存、农田、动物和设备的状态。操作后及每 5 秒保存，页面离开时再次保存；损坏存档会被校验拒绝并提示重新开始。
- 页面隐藏、手动暂停、查看弹窗时停止生长；刷新按已保存的剩余时间继续，没有离线追赶。
- 本机存档按浏览器和来源隔离。存储不可用时仍可游玩，显示无法保存的状态。
- 小屏的集市与加工清单在面板内部滚动，游戏页面保持一屏；极端小窗口允许受控页面滚动，确保操作可达。

## 文件

- `engine.js`：经济、种植、养殖、加工、订单、升级及存档校验，支持 Node 测试。
- `art.js`、`cover.svg`：原创田园插画、图标和大厅封面。
- `index.html`、`style.css`、`game.js`：界面、响应式布局、输入、生命周期和存档。
- `translations.js`：完整八国语言字典。
- `verify.cjs`：规则、经济通关、存档、语言与接入验证。

## 验证

运行 `node --test games/paper-farm/verify.cjs`。9 组测试覆盖：播种与一次浇水、成熟前收获保护、防重复奖励、零金币恢复、开地成本与失败事务、动物生产、全部八张订单及后续循环的真实经济通关、加工门槛、存档校验、八国语言完整性与占位符、清单及相对资源路径。

浏览器已实际操作：播种、浇水、一键收获、买鸡喂养与收蛋、前三张订单交付、升级解锁、确认开垦、建磨坊并加工收取面粉、集市出售、暂停保持、帮助、刷新续玩、大厅搜索与进入/返回的语言保留、取消重开及确认重开。控制台没有游戏错误。试玩进度已恢复到初始农场。

已检查 320×568、360×640、390×844、568×320、844×390、768×1024、1024×768、1280×720、1920×1080 的页面溢出和主要控件位置。八国语言分别检查 320×568 与 568×320，未出现横纵页面溢出或被裁掉的农田。小屏帮助在弹窗内滚动。大厅原字体支持的新字符已经补入子集并更新缓存版本。

未实测：实体触屏、浏览器 `file://` 双击模式；普通脚本、相对路径及无 fetch 依赖已做静态验证。
