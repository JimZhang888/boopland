# 纸上台球 · Paper Billiards

偏写实的俯视 2D 台球游戏：深绿台呢、木质球桌、六袋口、球体高光和阴影。外围保留 Boopland 的暖纸色界面。纯 HTML、CSS、JavaScript、Canvas 和 SVG，无联网素材、依赖安装或构建步骤。

从大厅搜索「纸上台球」进入，入口为 `games/paper-billiards/index.html`。

## 玩法

- **清台练习**：任意顺序打进全部 15 颗球，以更少杆数完成。白球落袋后自由摆放。记录最佳清台杆数。
- **双人八球**：两人在同一设备轮流操作。第一颗合法进球确定全色 / 花色，包括开球。进自己的球可继续击球，否则换人。
- 双人模式中，白球落袋、未碰球、先碰错球，或接触目标球后既未进球也没有球碰库，判为犯规；对方获得全台自由球。犯规时打进的目标球不取回。
- 清完自己的球组后，下一杆才能合法打进 8 号球。提前打进 8 号，或打进 8 号时伴随犯规，均判负，开球也适用。不需要指定袋口。
- 这是简化的休闲八球规则；没有电脑对手、联网匹配、杆法旋转或比赛级开球细则。

## 操作

- 点击球桌选择方向，调整力度滑条后点击「击球」。空心球与虚线显示预计的首次接触位置，碰撞后目标球与白球的短线仅为方向参考。
- 从白球附近按住鼠标或手指向后拉，松开击球。拉动距离控制力度，轻点不会出杆；`Esc` 取消拖杆。
- 左右方向键微调方向，按住 `Shift` 时更精细；上下方向键调整力度，空格击球。滑条保留原生键盘操作。
- 自由球时点击空位放置白球；也可直接点击「放置白球」使用当前提示位置。与球重叠、袋口及桌外不可放置。
- `P` / `Esc` 暂停或继续。切换标签页自动暂停；开局后的窗口失焦也会暂停。打开说明和新局确认期间冻结模拟。
- 新局和中途切换玩法需在游戏内确认，取消后继续原局。右上角可开启合成击球、碰撞、碰库和落袋音效；默认静音。
- 根据可用空间自动横向或竖向显示球桌，切换尺寸保留球局；球上的号码保持正向。

## 文件

- `engine.js`：固定 1/240 秒步长的球体碰撞、滚动阻力、分段库边与袋口、自由球、双人分组和胜负。可在 Node 中独立运行。
- `scene.js`：缓存的木纹和台呢、球体与球杆、瞄准线、落袋动画、横竖屏坐标变换。绘图设备像素比最多为 2。
- `game.js`：鼠标 / 触摸 / 键盘输入、暂停、弹窗、音效、成绩、界面与模拟同步。闲置时仅在画面变化时重绘，后台暂停动画帧。
- `translations.js`：中、英、日、韩、法、德、西、巴西葡语，接入 `../../i18n.js`。语言入口仅在欢迎页，返回大厅链接保留语言参数。
- `cover.svg`：大厅封面与图标；所有资源使用相对路径与普通脚本，不使用模块或 `fetch` 读取本地数据。
- 存储键 `boopland-paper-billiards-v1`：最佳清台杆数及音效开关。刷新后重新摆球，不恢复未完成的一局。存储不可用不阻止游戏。
- 使用全站 `../../analytics.js`；本地文件及回环地址不发送统计请求。

```sh
node --test games/paper-billiards/engine.test.cjs
```
