# 纸上台球 · Paper Billiards

偏写实的俯视 2D 台球游戏：深绿台呢、木质球桌、六袋口、球体高光和阴影。外围保留 Boopland 的暖纸色界面。纯 HTML、CSS、JavaScript、Canvas 和 SVG，无联网素材、依赖安装或构建步骤。

从大厅搜索「纸上台球」进入，入口为 `games/paper-billiards/index.html`。

## 玩法

- **清台练习**：任意顺序打进全部 15 颗球，以更少杆数完成。白球落袋后自由摆放。记录最佳清台杆数。
- **双人八球**：两人在同一设备轮流操作。第一颗合法进球确定全色 / 花色，包括开球。进自己的球可继续击球，否则换人。
- 双人模式中，白球落袋、未碰球、先碰错球，或接触目标球后既未进球也没有球碰库，判为犯规；对方获得全台自由球。犯规时打进的目标球不取回。
- 清完自己的球组后，下一杆才能合法打进 8 号球。提前打进 8 号，或打进 8 号时伴随犯规，均判负，开球也适用。不需要指定袋口。

## 操作

- 点击球桌选择方向，调整力度滑条后点击「击球」。空心球与虚线标出几何接触位置。能碰到目标球时，短线按当前力度和击点预演碰撞后两球的走向。
- 点击操作栏的「击点」，按出杆视角在母球上点选或拖动。上方是高杆，下方是低杆，左右两侧是左塞、右塞。斜向可以组合，虚线圈标出最大偏移。方向键每次微调 10%，Home 回中。每杆结束后，击点回到中心。
- 近距离瞄准目标球正面时，高杆会跟进，低杆能拉回。球在台呢上滑行得越远，倒旋越容易耗尽。左右塞在碰库时改变反弹角度，球与球接触时也会产生横向偏移。
- 从白球附近按住鼠标或手指向后拉，松开击球。拉动距离控制力度，轻点不会出杆；`Esc` 取消拖杆。
- 点按左右微调按钮或按左右方向键，每次转动 0.10°。按住 `Shift` 微调时每次转动 0.01°。上下方向键调整力度，空格击球。滑条保留原生键盘操作。
- 自由球时点击空位放置白球；也可直接点击「放置白球」使用当前提示位置。与球重叠、袋口及桌外不可放置。
- `P` / `Esc` 暂停或继续。切换标签页自动暂停；开局后的窗口失焦也会暂停。打开说明和新局确认期间冻结模拟。
- 新局和中途切换玩法需在游戏内确认，取消后继续原局。右上角可开启合成击球、碰撞、碰库和落袋音效；默认静音。
- 根据可用空间自动横向或竖向显示球桌。号码、花带和母球红点随球面滚动，转屏时保留球局和球体姿态。

## 文件

- `engine.js` 以 1/240 秒步长计算运动。每步内按时间先后处理两球首次相切、碰库和落袋，瞄准线沿用相同的圆形几何。球堆开局时相互贴紧，同时接触的球共同分担冲量。台呢摩擦使滑动过渡为滚动，球间与库边的切向冲量传递侧旋。引擎也处理自由球、双人分组和胜负，可在 Node 中独立运行。
- `scene.js`：缓存的木纹和台呢、球体与球杆、瞄准线、落袋动画、横竖屏坐标变换。绘图设备像素比最多为 2。
- `game.js`：鼠标 / 触摸 / 键盘输入、暂停、弹窗、音效、成绩、界面与模拟同步。闲置时仅在画面变化时重绘，后台暂停动画帧。
- `translations.js`：中、英、日、韩、法、德、西、巴西葡语，接入 `../../i18n.js`。语言入口仅在欢迎页，返回大厅链接保留语言参数。
- `cover.svg`：大厅封面与图标；所有资源使用相对路径与普通脚本，不使用模块或 `fetch` 读取本地数据。
- 存储键 `boopland-paper-billiards-v1`：最佳清台杆数及音效开关。刷新后重新摆球，不恢复未完成的一局。存储不可用不阻止游戏。
- 使用全站 `../../analytics.js`；本地文件及回环地址不发送统计请求。

## 验证

在项目根目录运行：

```sh
node --test games/paper-billiards/engine.test.cjs
```

引擎与集成测试覆盖摆球、碰撞、六袋进球、开球、自由球、犯规、分组和胜负，以及八语文案和大厅入口。杆法用例覆盖四个出杆方向的跟进与回拉、左右塞碰库和传球、滑动到滚动的过渡、滚动距离与转角、原地自旋减速、斜向击点限幅，并将瞄准短线与实打轨迹对照。

内置浏览器通过 HTTP 静态预览实际验证：

- 按钮击球、力度滑条、拖杆释放出杆、球体散开、运动中暂停与恢复。
- 双人低力度未碰球判罚、玩家切换、自由球按钮放置。
- 玩法说明、重开确认取消、连续弹窗后的玩法切换确认；后者发现的异步关闭事件竞态已修复并复测。
- 大厅搜索返回唯一游戏卡片，封面加载成功，进入和返回保留 `lang=zh-CN`。
- 中文布局检查 `320×568`、`360×640`、`390×844`、`568×320`、`844×390`、`768×1024`、`1024×768`、`1280×720`、`1920×1080`。修复最小竖屏的横向溢出，并复测为零溢出、主要控件完整可见。
- 其他七种语言在 `320×568`、`568×320` 检查，无页面横纵溢出或未翻译键名。短横屏暂停的继续按钮完整可见。
- 大厅字体子集补充了新文案所需字符，字体缓存版本同步更新。

杆法改动在 Chrome 中直接打开本地游戏入口，实测触摸选点、键盘微调、按钮及拖杆出杆、暂停和杆后回中。桌面、平板、手机横竖屏共检查十种视口，另在 320×568 和 568×320 检查了八种语言的击点面板。触摸操作使用浏览器模拟，完整清台和双人胜负由引擎测试覆盖。
