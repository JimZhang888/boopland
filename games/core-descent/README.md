# 垂直极限

原生 HTML / CSS / JavaScript 的向下跳台小游戏。入口为 `index.html`，已登记到大厅。资源均为本地相对路径，无依赖和构建步骤。共用根目录语言设置，提供八国语言。

## 操作与规则

- 左右方向键或 A / D 移动；手机按住下方箭头，也可在画布上拖动指引方向。
- 走出平台边缘即可下落。空格、P 或暂停按钮暂停；切换窗口或标签页自动暂停。
- 共 6 格体力。首次落在岩石平台恢复 1 格，尖刺扣除 2 格，并有短暂受伤保护。
- 碎裂平台停留约半秒后坍塌，弹簧向上弹起，传送带推动角色。每五层有水晶。
- 避开顶部尖刺与画面下缘，落在第 999 层的平台上通关。每 200 层切换地层氛围，仍每 20 层提示进度。
- 本地保存最佳层数及音效偏好。音效默认关闭，由用户交互启用。

## 验证

运行 `node --test games/core-descent/engine.test.cjs`。9 项测试覆盖高速落地、单次回血、尖刺伤害保护、碎裂平台、弹簧及传送带、失足失败、顶端伤害、暂停重开、第 100 / 998 / 999 层的通关边界和 30 个种子的完整 999 层地图边界。

999 层更新已通过上述测试、脚本语法检查及八国语言和界面目标数值检查；本次未重新进行浏览器实玩。滚动速度与平台宽度仍使用原有难度上限，历史最佳纪录继续沿用。
