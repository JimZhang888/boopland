# 猫咪推箱子

帮小猫把每个纸箱推到绿色爪印上。12 个原创关卡，采用项目统一的纸张、铅笔线稿与低饱和配色；没有倒计时，可以随时选关。

## 运行

从项目根目录的 `games.html` 进入「猫咪推箱子」，或直接双击本目录 `index.html`。纯原生 HTML / CSS / JavaScript，无安装、构建或后端依赖，支持 `file://`、普通静态服务器和子目录部署。

## 操作

- 方向键 / WASD：移动；一次只能推一个箱子，不能拉。
- 手机：滑动棋盘、点击相邻格，或点击屏幕方向按钮。
- Z / 撤销：撤销一步，包括推动与最后一步通关动作。
- R / 重来：重新开始当前关卡。
- 选关：12 关均可直接选择；选择关卡会从该关初始状态开始。
- 问号：查看玩法；Esc 关闭弹窗。

无目标的死角、无法到达目标的边缘以及完全堵住的 2 × 2 箱群会提示撤销；未穷举所有组合死局。通关后可继续下一关、重玩或返回选关。

## 进度与语言

当前关卡、完整操作记录和每关最佳步数保存在当前浏览器的 `boopland-cat-sokoban-v1`。刷新可继续，并保留撤销历史。最佳成绩优先比较步数，步数相同时比较推动数。禁用存储时仍可游玩，损坏存档安全回退到初始状态。

共用根目录 `i18n.js` 的中文、英文、日语、韩语、法语、德语、西班牙语和葡萄牙语设置；仅欢迎页提供语言切换入口。动态状态、弹窗、无障碍标签、大厅卡片及返回链接均覆盖；语言变化、旋转和窗口缩放不重置当前棋局。

## 验证

运行核心测试：

```sh
node --test games/cat-sokoban/engine.test.cjs
```

20 项测试覆盖推箱规则、边界、通关、撤销、存档重放、死局检测和地图有效性。测试中的独立搜索器为全部 12 关寻找可执行解，并逐步验证通关及完整撤销。

已在 Chrome 无头浏览器实测：

- 真实键盘事件完成全部 12 关；方向按钮、原生触摸滑动和相邻格点击。
- 通关弹窗、下一关、选关、最终结局、最佳成绩、通关后撤销。
- 刷新恢复、坏存档、禁用存储、弹窗输入隔离、语言变化及旋转保留状态。
- 大厅搜索、八国语言卡片、封面加载、进入及返回；`file://` 和 HTTP 子目录访问。
- `320×568`、`360×640`、`390×844`、`568×320`、`844×390`、`768×1024`、`1024×768`、`1280×720`、`1920×1080`；八种语言另在小竖屏与短横屏检查，无页面溢出或关键按钮裁切。
- 无脚本异常或资源加载失败；弹层内容较长时可在弹层内部滚动。

极端小窗口允许受控页面滚动，优先保留操作可达性。未在实体手机或 Safari / Firefox 中实测。
