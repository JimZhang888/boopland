# 一页侦探

入口：`index.html`。根目录 `gamelist.js` 已登记，分类为「解谜」。

三个原创日常悬案：雨夜的来信、歪掉的画、消失的月光花。每案包含一幅现场 SVG、三位证人的证词、六件物证、两处可证实的矛盾，以及一条由三件事组成的时间线。没有倒计时、扣分或强制关卡解锁。

## 玩法

1. 点击现场的六个数字标记收集物证，在手记中查看详情。
2. 在「证词」页选择一位证人，再选择一件物证，点击「指出矛盾」。错误组合不会清除进度。
3. 收齐六件物证、找出两处矛盾后，点击「还原事件」。选择移动物件的人，通过上下箭头排列事件。
4. 提交正确推理后阅读完整经过。可以进入下一案，也可以从案卷夹选择任意案件。

「一点提示」按当前进度提示尚未调查的物件、需要比对的证词，或时间线的第一步。「重新调查」只清空当前案，需在游戏内确认。

鼠标和触屏均使用点选；键盘用 Tab、Enter / Space 操作按钮，证词 / 物证 / 矛盾标签支持左右方向键及 Home / End，弹窗支持 Escape。窄屏使用上下分区，短横屏使用左右分区；长证词及结案内容在面板或弹窗内部滚动，返回大厅和主要操作保持可达。

## 文件与状态

- `cases.js`：案件结构、场景热点和中英文叙事。
- `case-translations.js`：其余六种语言叙事，并注册至共享翻译服务。
- `translations.js`：八种语言的静态、动态、提示和无障碍文案。
- `engine.js`：搜证、矛盾验证、排序、结案及存档校验。
- `game.js`：界面、键盘、弹窗、语言同步与本地存档。
- `art.js`、`cover.svg`、`paper.svg`：原创矢量场景、人物头像、封面和纸纹。
- `style.css`：纸张、铅笔线稿、低饱和配色及横竖屏适配。

纯 HTML/CSS/JS，无构建步骤、额外运行依赖、远程素材或数据请求。全部资源使用相对路径，代码兼容 `file://` 和网站子目录。按项目规则引入公共 `i18n.js` 与 `analytics.js`；仅欢迎页切换语言。

存储键为 `boopland-one-page-detective-v1`。自动保存当前案、物证、矛盾、选择、时间线及结案状态，读取时校验类型、范围、重复条目和结案条件。存储不可用时仍能在当前页面游玩。无音效、定时器或后台动画循环。

## 验证

运行 `node games/one-page-detective/verify.cjs`：穷举三案的 54 种证词／物证组合和 54 种人物／时间线组合，验证每案仅有一个有效结论；验证重复搜证、重复矛盾、排序边界、异常存档、八语文案和参数一致性、本地资源及大厅登记。

浏览器已实测：三案从搜证到结案的完整流程；错误物证、人物与顺序的反馈；渐进提示；刷新恢复；案卷切换；主站跨标签切换语言且进度不变；八种语言加载；大厅中文搜索、进入和返回；重新调查、取消以及其他案件进度保留；键盘切换标签与 Escape 关闭弹窗；HTTP 子目录访问、资源加载及语言链接。

布局实测：320×568、360×640、390×844、568×320、844×390、768×1024、1024×768、1280×720、1920×1080。八种语言额外检查 320×568 与 568×320，均无页面溢出及主要控件越界。长内容允许在手记和弹窗内部滚动。控制台无脚本或资源错误。

未使用实体触屏设备验证，浏览器小屏检查不等于实机触摸测试。浏览器工具禁止 `file://` 导航，因此直接双击方式仅完成脚本和相对资源静态检查，未声称实测通过。极端小窗口允许受控滚动以保持操作可达。
