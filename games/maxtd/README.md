# 纸上防线 · MaxTD

从 `D:\WorkSpaceAI\Projects\MaxTD` 的 Paperline TD 1.2.2 移植到 Boopland。
战斗引擎和原创矢量美术沿用源项目；保留 20 × 13 自由布防、八种单位、自动寻路、无限波次、升级/回收、加速、音效和本地战绩。

## 打开

在根目录 `games.html` 搜索 **MaxTD** 或 **纸上防线**，点击卡片进入。
也可直接打开本目录 `index.html`。所有运行资源均为本地相对路径，不需要安装依赖、构建、后端或联网。
普通静态服务器及网站子目录部署同样可用。

## 操作

- 点击单位卡片，再点击战场格子部署；沙袋支持按住拖动连续放置。
- 点击已部署单位，在下方升级或回收。
- 点击开始按钮出兵；之后自动衔接波次，同一按钮可暂停或恢复。
- 数字 1–8 选兵，空格开始/暂停，Q 切换路线，Esc 取消，U 升级，Delete 回收。
- 聚焦战场后，用方向键移动光标，Enter 部署或选中。
- 战绩面板可重开。手册、详情和战绩弹窗会暂缓战斗；进入后台会暂停。

## 大厅适配

- 使用根目录 `BooplandI18n` 的统一语言状态，支持中文、英语、日语、韩语、法语、德语、西班牙语和巴西葡萄牙语。
- `i18n.js` 只注册 `maxtd` 作用域的文案，不再单独保存游戏语言。
- 切换语言保留当前对局，返回链接携带 `lang`，弹窗内也有直接返回大厅入口。
- `h5.css` 提供一屏布局；`app.js` 根据可用宽高完整容纳战场，缩放/旋转不会重建对局。
- 短横屏和最小竖屏精简装饰与单位插画，保留全部八种部署按钮和主要操作。极端小窗口、放大文字允许必要滚动。
- 战绩使用 `boopland-maxtd-records-v1`，不覆盖源项目或其他游戏的记录；存储不可用时仍可游玩。
