# 快递分拣局

入口为 `index.html`，已在根目录 `gamelist.js` 登记，可从 `../../games.html` 进入。
全部脚本为普通脚本，资源使用相对路径，无需构建、安装依赖或联网字体。共用根目录的八国语言与访问统计设置。

- 拖动包裹到同名站点，或先点包裹再点站点。
- 数字键 1 / 2 / 3 投递选中包裹；空格暂停或继续。
- 90 秒轻松班与 60 秒高峰班；每局 5 次机会。5 连击起双倍，10 连击起三倍。
- 最佳分数按班次保存在本机；切换页面会暂停。

## 验证

运行 `node games/parcel-sorter/verify.cjs` 检查规则、完整班次模拟、八国语言字典、资源路径和大厅登记。

已通过本地 HTTP 浏览器验收：大厅搜索、进入与返回、语言参数、开局、正确投递、失误结算、暂停和重开，控制台无错误。
实测视口：320×568、360×640、390×844、568×320、844×390、768×1024、1024×768、1280×720、1920×1080，页面无横纵向溢出。八种语言均在 320×568 检查，葡萄牙语结算另测 568×320。

内置浏览器的 URL 安全策略不支持 `file://`，因此双击打开只完成了路径和普通脚本兼容性检查，未实测。支持触摸 Pointer Events，但未进行实体触屏设备测试。
