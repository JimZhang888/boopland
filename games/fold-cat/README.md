# 折页寻猫

独立入口为 `index.html`，大厅分类为「解谜」。小猫会自己沿屋脊前进，在断路处停下。沿虚线折起纸带可让分开的屋檐相接，带小猫走进亮灯的小屋。六页地图逐步引入过桥后展开、横纵折痕和多道折痕的先后顺序。

- 等小猫停稳后，点击地图上的折痕或底部按钮，即可折起或展开对应纸带。键盘数字 1 至 3 分别操作 A、B、C。
- 每次折纸后，小猫自动走到下一个断点或家门。小猫脚下的纸带会保持展开，等它离开后就可以操作。
- 「提示」指出当前局面下一道可用的折痕。页码按钮可重玩已解锁关卡。浏览器本地保存通关记录，禁用存储时仍可走完六页。

原生 HTML、CSS、JavaScript、SVG，无需安装或构建。所有游戏资源随页提供，站点语言和返回链接使用项目公共接口。
