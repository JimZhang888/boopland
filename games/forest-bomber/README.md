# 森林炸弹人

纸张质感、铅笔线稿的单人炸弹人小游戏。小狐狸与三位电脑伙伴在格子森林中对战，放炸弹、炸木箱、捡道具，并利用连锁爆炸围堵对手。已登记在大厅的「动作」分类。

入口为 `index.html`。使用原生 HTML、CSS、Canvas 与普通 JavaScript；资源全部保存在本游戏目录，共用项目的 `../../i18n.js` 和 `../../analytics.js`。无需安装依赖或构建，可通过静态服务器或直接打开 HTML 运行。

## 操作

- 方向键 / WASD：按住连续四向移动，轻按走一格，格子之间平滑移动。
- 空格 / J：放置炸弹。移动途中按下，会在下一格放下；按住不会连续放弹。
- P / Esc：暂停或继续。打开手册、窗口失焦、隐藏页面也会暂停；隐藏页面停止动画和音频，恢复时保留暂停状态。
- 手机：按住屏幕方向按钮，另一只手点炸弹按钮；支持分别追踪多个触点和指针取消。
- 音效默认关闭，点击声音按钮后才启用。本地记录最高分，存储被禁用时仍可游玩。
- 手册、暂停、结算和重新开始均在当前屏幕内；帮助弹窗的长说明可以单独滚动。

## 规则

- 五片林地，每关 150 秒、三位电脑对手。初始三颗爱心，击败所有对手过关；过关恢复一颗爱心并保留道具。爱心耗尽或超时失败，第五关获胜完成冒险。
- 地图为 13 × 11 格，四角均有起始退路。随机木箱和隐藏道具由种子生成，每次重开重新生成。
- 炸弹引信 2.4 秒，十字火焰持续约 0.6 秒；石头不能炸毁，每条射线在第一个木箱处停止。炸弹阻止走入，刚放下时可以从所在格走出来。
- 火焰会立即点燃沿途炸弹，连锁继承各炸弹自己的火力。一次爆炸批次使用同一份障碍快照，避免刚被炸掉的木箱意外让同批火焰穿透。
- 自己和对手的炸弹都会伤害玩家。受伤后有 1.65 秒无敌；叶盾抵挡一次伤害，不叠加。
- 四类道具：炸弹容量 +1（最多 5）、爆炸范围 +1（最多 6 格）、移动加速（最多 8 格/秒）、叶盾。木箱中的道具在火焰结束后出现；已露出的道具会被后续爆炸摧毁，电脑也可拾取。
- 电脑预测炸弹引爆时间与连锁危险，放弹前搜索可达的避难格；会炸开通路、寻找道具、接近对手并撤离火线。
- 得分：玩家炸木箱 +15，玩家捡道具 +40，对手出局 +250。包含玩家炸弹的连锁每多一颗 +50；同一时刻爆炸但互不相连的炸弹不计连锁。过关奖励 500 + 剩余整秒 × 5。
- 支持简体中文、英语、日语、韩语、法语、德语、西班牙语、巴西葡萄牙语；沿用全站语言设置，返回大厅保留语言，切换语言不重置进度。

## 文件

- `engine.js`：地图、格子移动、炸弹与连锁、道具、伤害、闯关与电脑行为；可独立在 Node 中验证。
- `scene.js`：纸感地图、狐狸与伙伴、木箱、石头、道具、炸弹读秒、火焰预警和轻量粒子。
- `game.js`：键盘与多点指针输入、动画循环、HUD、开始／暂停／结算、音效与存储。
- `translations.js`：八国语言静态与动态文案。
- `style.css`、`cover.svg`：一屏响应式布局及大厅手绘封面。
- `engine.test.cjs`、`runtime.test.cjs`：规则与真实输入处理器的回归测试，无额外测试依赖。
