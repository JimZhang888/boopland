# 纸间飞钩 · Paper Hook

参考单键飞钩摆荡玩法的原创纸质手绘小游戏。原生 HTML / CSS / JavaScript，无安装、构建、图片下载或后端依赖。入口为 `index.html`，已在大厅 `gamelist.js` 登记。

## 操作

- 按住画面、下方按钮或空格，自动挂住附近前方的圆环。虚线和亮起的圆环提示目标。
- 荡到右上方时松开，保留速度飞出去；再按住接上下一个圆环。尚未进入范围时，持续按住会在接近后自动挂钩。
- 越过终点旗即可通关，三颗星星是额外挑战。橙色弹跳垫提供向上的弹力；碰到红色风轮或落出画面会失败，可以立即重试。
- `P` / `Esc` 暂停或恢复，`R` 重试。关卡标题打开旅程手册，右上角提供帮助、暂停和音效开关。

## 内容和实现

- 3 章、12 关：基础摆荡、弹跳与障碍、移动风轮；每关 3 颗星。
- 120 Hz 固定步长物理：重力、单向绳长约束、切向助力、惯性飞行、平台碰撞。
- Canvas 手绘火柴人、纸山、云朵、飞行轨迹和纸屑反馈；设备像素比最高为 2，改变屏幕尺寸保留当前游戏状态。
- 触控采用 Pointer Events、指针捕获和取消处理；键盘与鼠标可共同使用。切换标签或窗口失焦时暂停，返回后手动继续。
- 进度、最佳星数和最快用时保存在 `boopland-paper-hook-v1`，音效设置保存在同名前缀的 `-sound` 键。禁用存储时仍可正常完成当前会话。
- 共用根目录 `i18n.js`，提供完整中、英、日、韩、法、德、西、巴西葡语文案；返回大厅保留语言。没有额外语言选择器。
- 音效为本地 Web Audio 合成，默认关闭；装饰反馈遵循 `prefers-reduced-motion`。

## 验证

从项目根目录执行：

```sh
node --test games/paper-hook/engine.test.cjs
```

22 项测试通过，覆盖每一关的真实按住/松手三星通关路线、绳长和释放速度、缓冲挂钩、暂停、弹跳、静止与移动危险物、失败、星星去重、异常存储、语言完整性和大厅资源。

已在浏览器检查：

- `320×568`、`360×640`、`390×844`、`568×320`、`844×390`、`768×1024`、`1024×768`、`1280×720`、`1920×1080` 的布局和主要控件可见性，没有页面横向或纵向溢出。
- 全部八种语言在 `320×568` 和 `568×320` 下的文字与操作；帮助和选关弹窗允许内部滚动。
- 鼠标连续四次挂钩、第一关三星通关、下一关、失败结算、暂停与 `P` / `Esc` 恢复、关卡解锁和刷新后读取进度。
- 大厅搜索、封面、进入游戏及返回大厅，HTTP 静态访问正常。

未实测：真实手机触摸、移动浏览器音频、不同操作系统的字体，以及 `file://` 直接双击访问（验收浏览器只允许 HTTP(S)）。资源均为相对路径和普通脚本，没有模块或 `fetch` 加载，按项目约定保留直接打开能力。
