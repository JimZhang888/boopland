# 一个消消乐

原生 HTML / CSS / JavaScript 三消小游戏，入口为 `index.html`，大厅已通过 `gamelist.js` 登记。没有构建步骤、外部素材或运行时依赖，资源均使用相对路径；保留项目公共语言设置和访问统计加载器。

## 玩法

- 点击两个相邻动物，或向相邻格拖动/滑动，交换它们的位置。横向或纵向连续三个及以上相同动物即可消除。
- 每关 26 步，只有产生消除的交换才扣一步。每只动物 60 分，掉落连消依次增加倍率，最高 5 倍。
- 第一关目标 3,600 分，后续每关增加 600 分。达到目标、目标的 1.4 倍、1.8 倍分别获得一至三星；用完步数后结算。
- 提示不限次数；每关两次免费洗牌。没有可用交换时自动免费重排，不扣步数或道具次数。
- 无倒计时。方向键移动焦点，空格/回车选择，Esc 取消。帮助弹层可随时打开，重开前可取消。
- 最高分和音效偏好保存在本地；存储不可用时仍可正常游戏。音效由用户主动开启，隐藏页面时静音。

## 美术与适配

`art.js` 内为原创 SVG 手绘动物头像：橙狐、蓝猫、粉兔、绿蛙、黄鸡、紫熊。使用独立轮廓、五官、柔和填色与铅笔排线，兼顾颜色和形状识别。封面复用相同动物形象。

棋盘根据容器剩余宽高等比缩放，手机横屏将状态放到左侧，竖屏放到上方。支持减少动态效果偏好。静态文案、动态反馈、按钮、无障碍标签和大厅卡片均提供八种语言。
