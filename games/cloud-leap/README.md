# 云间来信 · 跳一跳

低饱和手绘风的蓄力跳跃游戏。原创小女孩在薄雾浮岛之间前进；场景与角色使用 Canvas 绘制，纸纹和封面使用本目录的 SVG。

## 入口与运行

- 在根目录 `games.html` 搜索“跳一跳”或“云间来信”。
- 游戏入口为 `games/cloud-leap/index.html`，已在 `gamelist.js` 唯一登记，附七种外语卡片文案。
- 原生 HTML、CSS、普通 JavaScript，相对路径，无构建、后端、远程字体、CDN、fetch 或 ES 模块依赖。
- 引入公共 `../../i18n.js` 和 `../../analytics.js`，语言设置随全站，返回大厅保留语言参数。

## 操作

- 按住场景、下方按钮或空格键蓄力，松开向下一座发光浮岛跳跃。浅绿蓄力区域提供落点参考。
- 成功落岛 +1，命中花心 +2；连续花心命中每跳加分依次为 2、3、4、5，此后保持 5。
- P / Esc 或暂停按钮暂停与继续；R 或重开按钮重新开始；说明打开时冻结游戏。
- 切后台或窗口失焦自动暂停，恢复后手动继续，跳跃时间不突进。取消触摸会撤销蓄力。
- 音效默认关闭，由用户开启；最高分与音效偏好保存在本浏览器，存储不可用时仍可游玩。

## 验证

在项目根目录运行：

```powershell
node --test games/cloud-leap/game.test.cjs
```

5 项自动检查通过：蓄力上下限、左右方向与变化距离的花心落点、椭圆碰撞边界、八国语言键与占位符、唯一大厅登记与本地资源路径。

内置浏览器通过静态服务器实测了花心落岛加分、跳跃中暂停与继续、说明、跳空结算和重开，以及大厅搜索“跳一跳”、进入与返回、语言参数传递。

布局检查覆盖 `320×568`、`360×640`、`390×844`、`568×320`、`844×390`、`768×1024`、`1024×768`、`1280×720`、`1920×1080`，页面无横纵溢出，主要按钮在视口内。八国语言另检查了 `320×568` 与 `568×320`。

验证限制：内置浏览器安全策略只允许 HTTP/HTTPS，拦截了 `file://` 直开测试；已检查普通脚本与本地相对路径兼容性。未使用真实手机触摸硬件，未验收音效听感。
