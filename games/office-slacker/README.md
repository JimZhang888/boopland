# 上班摸鱼

原生 HTML / CSS / JavaScript 的单键反应小游戏。暖白纸张、铅笔描边和低饱和办公室；场景为可动画的内联 SVG，封面为独立 SVG，无第三方素材、运行依赖或构建步骤。

从项目根目录 `games.html` 搜索「上班摸鱼」进入，或直接打开本目录 `index.html`。资源使用相对路径，支持静态服务器及子目录部署；沿用全站八国语言、返回链接语言传递和统计加载器。

## 玩法

- 点击「开始上班」，一局 60 秒。按住按钮或空格摸鱼，松手立即工作；鼠标、触屏与键盘共用同一套规则。
- 摸鱼每秒 20 分，连续按住每 1.5 秒增加 0.5 倍倍率，最高 ×3。松手、暂停、被抓会清空连续倍率。
- 目标：坚持到下班并积累 800 分。存活但不足 800 分也会正常结算；达到目标获得「摸鱼优秀员工」。
- 老板有三种随机巡查：正常查看、只来续咖啡、走后突然回头。每三次巡查包含三种行为，顺序打乱；时间逐渐收紧，但真实查看前始终有不少于 800 毫秒的可见警告。
- 黄色脚步警告与回头预告本身不增加怀疑；只有红色「老板盯着你」时摸鱼才增加怀疑，每秒 90。工作或老板未看时每秒下降 45。
- 怀疑满 100 被抓，扣 100 分（最低为 0），训话 1.4 秒，之后需重新按住才能摸鱼。第三次被抓立即结束本局。
- 摸鱼累计时间推动刷手机、偷吃面、伸懒腰三种动画；电脑从表格切换为小鱼，配合表情、音乐符号与吐槽气泡。
- 顶部按钮或 P / Esc 暂停。页面隐藏、窗口失焦、打开说明时暂停；恢复需要主动点击继续。暂停会清除按住状态，并停止帧循环和声音。卡顿帧最多推进 80 毫秒，避免跳过反应提示。
- 音效默认关闭，用户点击开启后由 Web Audio 合成；无音频下载。最佳分保存在 `boopland-office-slacker-v1`，存储异常不会阻止游戏。
- 支持 `prefers-reduced-motion`；减少动作时仍保留摸鱼/工作/被抓的明确姿态、文字与危险提示。

## 验证

在项目根目录运行：

```sh
node --test games/office-slacker/engine.test.cjs
```

10 项测试覆盖计分与倍率、危险判定、释放输入、扣分与三次被抓、暂停与重开、卡顿反应窗口、三种巡查的公平预告、100 个随机种子的完整 60 秒策略游玩、存档清洗、八国语言键名/占位符、清单登记和本地资源路径。

内置浏览器的 HTTP 预览实测：

- 中文准备界面：320 × 568、360 × 640、390 × 844、568 × 320、844 × 390、768 × 1024、1024 × 768、1280 × 720、1920 × 1080，页面无横纵溢出，主按钮完整可见。
- 八国语言：320 × 568 与 568 × 320 的准备界面，标题与返回/工具不重叠，页面和操作按钮不溢出。
- 长按与空格计分、松手工作、暂停与继续、P 快捷键、说明弹窗和关闭后仍保持暂停、音效开关。
- 实际完成一局 60 秒：巡查、咖啡假动作、被抓扣分、正常结算与重开；刷新后最佳分保留。568 × 320 的结算按钮完整可见。
- 大厅搜索得到唯一游戏卡片，进入和返回均保留语言。检查游戏页面控制台未发现脚本错误。

验证限制：未使用实体触摸设备或人工听音；三次被抓的终局、800 分达标、全部随机巡查分支、存储被禁用和卡顿边界由自动测试/代码检查覆盖，不等同于全部浏览器人工试玩。直接双击方式已检查相对路径和无模块/fetch依赖；浏览器工具不支持 file://，未直接实测。
