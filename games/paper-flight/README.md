# 纸飞机

入口为 `index.html`，大厅通过根目录 `gamelist.js` 登记。原生 HTML、CSS、Canvas 和普通 JavaScript 脚本，无安装、构建或联网素材依赖。

## 操作与玩法

- 鼠标移动、手指拖动、方向键或 WASD 控制纸飞机，自动射击。
- 空格或「橡皮擦」按钮清除可见敌机和敌弹，每局两次。
- P / Esc 或暂停按钮暂停，再次操作可继续；离开窗口或切换标签页自动暂停。
- 每局三次机会，受击后短暂无敌；每 18 秒推进一波，逐步加入会射击的敌机。
- 击落敌机获得分数，每六次击落掉落道具，依次为三向火力、护盾、修复。
- 音效默认关闭，通过按钮开启；最高分保存在本地，存储不可用时仍能游玩。
- 语言沿用全站八国语言，切换语言不重置本局；返回大厅保留语言参数。
