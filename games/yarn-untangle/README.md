# 毛线解结 · Yarn Untangle

在纸张桌面上拖动毛线的线头或中间圆点，让所有交叉逐渐消失。解开最后一处后，整幅线团平缓展开、出现小花瓣和完成印章。无计时、无步数限制。

## 运行与集成

- 入口：`games/yarn-untangle/index.html`。大厅归类「解谜」，可搜索「毛线解结」。
- 原生 HTML / CSS / JavaScript / SVG，无构建、后端、CDN 或数据 fetch；所有运行资源使用相对路径。
- 通过 `../../i18n.js` 使用全站八国语言，返回大厅保留 `lang`；无独立语言开关。
- `../../analytics.js` 只复用全站访问统计，本地预览自动跳过。

## 操作与进度

- 鼠标或触屏：拖动任意圆点；交叉计数在移动时实时更新，松手确认完成。
- 键盘：Tab 选择节点，方向键移动，Shift 加大距离，Esc 取消当前拖动。
- 撤销恢复上一步；重新理恢复本关初始布局；提示展示一个未被节点占据的参考位置，不自动代玩。
- 12 个固定关卡，2–4 根毛线、4–18 个节点，收集册可自由选择关卡。
- 使用 `boopland-yarn-untangle-v1` 保存本关位置、步数和已完成关卡。刷新保留进度；撤销历史只存在于当前页面。损坏或不可用的存储不阻塞游玩。
- 重叠线段、非相邻端点接触、节点挤在一起均不会误判完成。成功动画使用统一平移与缩放，保持已解开的几何关系。
- 遵循 `prefers-reduced-motion`；失焦、隐藏页面或调整窗口会取消未完成的拖拽，隐藏页面停止完成动画。

## 验证

在项目根目录执行：

```powershell
node --test games/yarn-untangle/engine.test.cjs
```

10 项自动测试覆盖交叉/接触/共线、邻接线重叠、节点退化、12 关可解性、舒展过程、提示参考解、480 种任意布局恢复、存储输入、八国语言占位符和大厅唯一登记/资源路径。

已在浏览器静态 HTTP 预览中实测：鼠标拖拽、第一关及第四关通关、舒展动画、通关后撤销、键盘移动与撤销、提示拖动、下一关、选关、刷新续玩、帮助与收集册弹层、大厅搜索和往返语言传递。无浏览器脚本错误。

布局检查覆盖 320×568、360×640、390×844、568×320、844×390、768×1024、1024×768、1280×720、1920×1080。八国语言的完成状态均检查了全部九种尺寸；游玩状态另外检查了八国语言的四类关键尺寸。未见页面溢出或主要操作与底栏重叠。手机横竖屏与桌面有实际截图检查，未进行实体触屏设备测试。

测试浏览器策略不允许 `file://` 导航，因此双击本地 HTML 尚未实测；已检查普通脚本加载、相对资源路径和不依赖 HTTP 的实现方式。屏幕阅读器朗读和系统减少动态效果设置未进行人工端到端验收。
