# 蜘蛛纸牌

入口：`index.html`。已登记到根目录 `gamelist.js` 的「棋牌」分类，可在大厅搜索「蜘蛛」。使用原生 HTML、CSS、JavaScript 和本地 SVG，无构建步骤、依赖安装或后端。

## 玩法

- 提供单色、双色、四色模式，默认单色。104 张牌，十列牌桌，初始 54 张，牌库剩余 50 张。
- 将纸牌按 K、Q、J、10…2、A 整理。同花色的完整一组会自动收走，收齐八组获胜。
- 单张牌可接在任何花色的大一号牌下；空列可以放任意牌。一起移动的牌必须同花色且连续降序。
- 发牌给十列各加一张，共五轮；存在空列时需要先填上。
- 初始 500 分，每次移牌或发牌扣 1 分，完成一组加 100 分。撤回完整恢复牌面、翻牌、收牌、牌库和得分，计时不回退。
- 提示按收组、翻开暗牌、同花色衔接等因素排序，重复点击切换合法建议。提示不是求解器，随机牌局不保证有解。
- 支持新开一局、重玩原发牌、暂停、自动保存和刷新续局。打开弹层或切换到后台时停止计时。存储不可用时仍可正常游戏。

## 操作与适配

- 鼠标或触屏点选纸牌后选择目标列，也可以拖动连续牌组；再次点击原选择或按 Esc 取消。
- 点击列号展开整列，以较大的按钮选择牌组。长牌列支持列内滚动，也可通过展开视图操作。
- 方向键在牌和列之间移动焦点，Enter / 空格确认，U 撤回，H 提示，D 发牌，P 暂停。
- 手机竖屏使用两排、每排五列；短横屏将发牌和操作区移到侧边。极端小窗口允许受控滚动以保留可操作的尺寸。
- 纸张纹理、铅笔线稿、低饱和绿与豆沙红延续项目风格；遵循减少动态效果设置。
- 使用全站 `BooplandI18n` 的八种语言。翻译覆盖状态、弹层、无障碍标签和大厅卡片，返回大厅保留语言。游戏内不增加语言切换入口。

## 文件

- `engine.js`：无 DOM 的规则、确定性洗牌、提示与合法操作回放。
- `game.js`：牌桌、指针与键盘输入、弹层、计时与存档。
- `translations.js`：八国语言字典。
- `style.css`、`paper.svg`、`cover.svg`：界面、纸纹和大厅封面。
- `engine.test.cjs`：规则与状态完整性测试。

存储键为 `boopland-spider-solitaire-v1`。保存难度、初始牌局种子、合法操作序列和用时；恢复时重新执行并验证每一步，非法存档不会生成异常牌面。撤回历史随存档恢复。

## 验证

从项目根目录运行：

```text
node --test games/spider-solitaire/engine.test.cjs
```

8 项测试通过：各难度牌数与牌型、合法/非法移动、混合花色、完整收组与连锁收组、发牌限制、胜利、操作回放与非法存档，以及 60 个随机牌局在多步操作中的牌数守恒。

浏览器通过本机静态服务器实测：点选、拖牌、整组移动、自动翻牌、提示、发牌、撤回、刷新续局、暂停计时、难度切换、原局重玩、整列查看、说明弹层、大厅搜索与往返；控制台没有脚本错误。

实测视口：320×568、360×640、390×844、568×320、844×390、768×1024、1024×768、1280×720、1920×1080。正常游戏无页面横向或纵向溢出，主要控件在屏内。八种语言另覆盖 320×568、360×640、568×320、844×390，共 32 组布局检查；修复并复查了小屏长译文的溢出。说明弹层内滚动时关闭按钮保持可达。

另检查了 65 个翻译键及占位符一致性、静态资源路径、HTML 翻译绑定、唯一大厅登记、JavaScript 语法和差异空白。

未实测：浏览器测试工具禁止 `file://` 导航，因此直接双击文件仅完成相对资源和无服务器依赖的静态检查；未使用实体手机验证触摸和安全区。胜利与收组由引擎用例验证，未在浏览器中人工完成整盘随机牌局。
