# 深夜煎饼摊

纯静态的双锅煎饼经营小游戏。入口是 `index.html`，已登记在根目录 `gamelist.js` 的「休闲」分类。直接打开游戏或从 `../../games.html` 进入均可，无需安装、构建或联网。

## 玩法

- 一晚 120 秒，两口锅同时计时，最多接待三位客人。每 40 秒增加订单配料种类、缩短等候时间和补位间隔。
- 选锅，摊饼；正面煎到 2.4 秒即可翻面，2.4–4.8 秒内翻面计为最佳火候，8 秒未翻会煎糊。
- 翻面后按小票添加鸡蛋、薄脆、生菜、香肠和葱花。再次点击同一食材可取下。每份都需要鸡蛋。
- 反面至少煎 1.6 秒后可以卷饼，8 秒内卷好可保留完美品质，16 秒未卷会煎糊。
- 卷好后点击对应客人交单，配料须完全一致。交错单会减少客人耐心，但保留煎饼。卷好的饼停止加热。
- 14 秒内连续正确出餐积累连击；品质、客人剩余耐心和连击都会增加小费。烧糊、丢弃、交错单、客人离开会中断连击。
- 收摊后展示营业额、出餐数、最高连击、完美煎饼、离开的客人和丢弃数。最高营业额保存在本机；存储不可用时仍可正常游玩。

## 操作

鼠标或触屏点击锅、食材、操作按钮和客人。

| 按键 | 操作 |
| --- | --- |
| `1` / `2` | 选择煎锅 |
| `Space` | 摊饼、翻面、卷饼或清理烧糊的锅 |
| `Q W E R T` | 鸡蛋、薄脆、生菜、香肠、葱花 |
| `7` / `8` / `9` | 向左、中、右客人交单 |
| `X` | 丢弃当前锅里的饼 |
| `P` / `Escape` | 暂停或继续 |

打开玩法说明、切换标签页、窗口失焦或离开页面时暂停。回来后手动继续，避免计时跳跃。音效默认关闭，可通过顶部按钮开启。

## 实现

- `engine.js`：独立于 DOM 的订单、双锅状态机、火候、连击和结算逻辑。
- `game.js`：DOM 交互、键盘、暂停、可选 Web Audio 音效和本机记录。
- `art.js` / `cover.svg`：本地 SVG 手绘食材、六位客人、煎锅与大厅封面。
- `style.css`：纸纹与低饱和配色，一屏布局，适配横竖屏并支持减少动效设置。
- `translations.js`：完整八国语言字典，通过公共 `../../i18n.js` 注册；游戏内不另设语言开关。返回大厅保留语言参数。
- 通过 `../../analytics.js` 使用项目既有统计加载器，本地预览不发统计请求。


浏览器实测尺寸（CSS 像素）：320×568、360×640、390×844、568×320、844×390、768×1024、1024×768、1280×720、1920×1080；中文正常游玩无页面横纵溢出。八国语言分别在 320×568 和 568×320 检查了主要操作、标题、动态文案与语言返回链接。说明与结算弹层允许内部滚动。

实测双锅连续出餐、键盘空格、帮助暂停和恢复、完整 120 秒营业回合、收摊结算、重开、最高记录在刷新后保留，以及大厅搜索、封面加载、进入与返回。浏览器控制台未出现脚本错误。

验收限制：浏览器工具的安全策略不允许 `file://` 导航，因此直接双击方式只做了普通脚本、资源路径及无构建依赖的静态检查，实际运行使用本机静态 HTTP 服务器。实体手机触屏与真实音频播放尚未单独验收；触屏使用标准按钮点击事件。
