# 纸上迷你高尔夫 · Paper Mini Golf

纸质与铅笔线稿风格的侧视物理高尔夫。拖动蓄力，松手击球，在斜坡、沙坑与机关之间寻找落点，用尽量少的杆数完成 3 章、9 洞小旅程。玩法方向参考 [Golf on Mars](https://captaingames.itch.io/golf-on-mars)，关卡、场景与代码为本项目独立实现。

大厅 `games.html` 搜索「纸上迷你高尔夫」即可进入，也可直接打开本目录的 `index.html`。纯静态 HTML、CSS、JavaScript、Canvas 和 SVG；无需安装、构建、后端或联网素材。

## 操作与规则

- 在画面任意位置按住鼠标或手指，向击球方向的反方向拖动，松开挥杆。向左下拖，球就向右上飞。拖动距离控制力度，短点按不会消耗杆数。
- 也可用角度与力度滑条和「挥杆」按钮。角度 0° 向右、90° 向上、180° 向左，支持回头救球；方向键调整、空格挥杆。滑条聚焦时使用其原生键盘操作。
- 等球停稳再打下一杆。虚线显示下一小段轨迹；淡虚线保留上一杆路线。没有杆数上限，重开本洞会清零当前打数并保留最佳纪录。
- 斜坡影响滚动；沙地有更强的摩擦力，并将出球速度降至草地的 74%；赭色弹跳垫向上弹球。
- 灰绿色挡板周期性上下移动。圆形按钮打开对应闸门，在本洞内持续生效；有按钮的球洞必须先激活按钮，才能进洞。
- 球以较低速度靠近杯口时进洞。标准杆内为三星，超一杆为二星，其余完成为一星。完成本洞后解锁下一洞；记分卡可重玩已解锁球洞。
- `P` / `Esc` 暂停或继续，`R` 重开。拖动期间 `Esc` 取消瞄准，不计杆。切换标签页或失去窗口焦点自动暂停，需主动继续；打开说明或记分卡也会暂停。
- 音效默认关闭，可在右上角开启，使用本地 Web Audio 合成。

## 文件与保存

- `engine.js`：9 洞关卡、1/120 秒固定步长物理、坡面与挡板碰撞、滚动摩擦、休止判定、机关、轨迹预测、存档校验；可由 Node 独立加载。
- `scene.js`：Canvas 纸山、铅笔线条、沙地、机关、球与轨迹。按宽高完整容纳球场，高抛时调整视野以保留球与完整球场，设备像素比最高为 2；小屏球体保持可辨识尺寸。场景装饰延伸到画布边缘，不改变可玩区域。
- `game.js`：Pointer Events、指针捕获与取消、滑条与键盘、暂停、弹层、音效、状态同步与保存。窗口尺寸改变保留本洞状态；拖动中调整尺寸取消本次瞄准。
- `translations.js`：中、英、日、韩、法、德、西、巴西葡语，接入根目录 `i18n.js`。仅欢迎页提供语言选择，返回大厅链接保留 `lang` 参数。
- 进度键：`boopland-paper-golf-v1`。保存每洞最佳杆数和所在球洞；解锁由已完成记录推导。刷新后从本洞发球点开始，不恢复半途轨迹。
- 音效键：`boopland-paper-golf-v1-sound`。存储异常不阻止当前会话游玩，记分卡显示提示。
- 统计沿用 `../../analytics.js`；本地文件与回环地址预览不发统计请求。

```sh
node --test games/paper-golf/engine.test.cjs
```

通过内置浏览器的 HTTP 静态预览验证：

- 使用正常拖拽、滑条与键盘操作完成全部 9 洞，验证最终总杆数、逐洞解锁、按钮开门、沙地再击球、弹跳和移动挡板。
- 验证飞行中暂停与继续、记分卡选关、重开保留最佳成绩、刷新恢复记录、说明弹层和音效开关反馈。
