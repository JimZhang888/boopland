# 红心大战

入口为 `index.html`，已加入大厅「棋牌」分类，可搜索「红心大战」。原生 HTML、CSS、JavaScript 和本地 SVG，无运行依赖、构建步骤或后端，支持普通静态服务器及直接打开文件。

## 玩法

- 你与三位电脑玩家顺时针对局，每人 13 张牌，A 最大、2 最小。每局换三张牌，方向按左、右、对面、不换牌循环。
- 首墩必须领出梅花 2。有首出花色必须跟牌，否则可以垫其他花色。首出花色的最大牌收墩并领出下一墩。
- 红心每张罚 1 分，黑桃 Q 罚 13 分。首墩不能垫罚分牌，只有手中全是罚分牌时例外。
- 红心被垫出后才允许领出红心；仅剩红心时也可以领出。黑桃 Q 不会使红心破禁。
- 收齐 13 张红心和黑桃 Q 即「射月」：自己加 0，其他三人各加 26。
- 每局结束累计分数。任意玩家达到 100 时结束整场，总分最低者获胜，最低分并列则共享胜利。
- 电脑根据自己的手牌与公开出牌做选择，不查看对手暗牌。提示给出同样的启发式建议，不保证最优。

核心规则参考 [Bicycle Hearts](https://bicyclecards.com/how-to-play/hearts/)。本游戏明确采用上述首墩全罚分牌例外、固定射月计分和并列胜利约定。

## 操作与功能

- 鼠标或触屏点选纸牌，再按「换牌」或「出牌」确认。选中的牌可以再次点击取消。
- 方向键在可选牌间移动，Enter / 空格选择，H 提示，P 暂停，Esc 取消选择或关闭弹层。
- 非法牌自动禁用；换来的牌下沿标红；刚完成的牌墩会短暂停留，并标出获胜牌。
- 提供暂停、计分簿、上一墩回看、规则说明、新对局确认和逐局结算。
- 打开弹层或切换后台时暂停电脑出牌与收牌；关闭后继续。没有出牌时限。
- 自动保存并在刷新后恢复；存储键 `boopland-hearts-v1`。保存随机种子、合法操作日志和选牌状态，恢复时逐步验证操作。无效存档回退新游戏，存储不可用时仍能游玩。
- 八国语言复用全站 `BooplandI18n`，动态提示、无障碍标签、结算、规则及大厅卡片均有翻译。返回大厅保留语言；游戏内没有单独语言设置。
- 纸张纹理、铅笔轮廓、低饱和草木绿与豆沙红延续项目风格。手机竖屏双排手牌，短横屏右侧操作栏；极小窗口允许受控滚动。遵循减少动态效果设置。

## 文件

- `engine.js`：可复现洗牌、换牌、合法出牌、电脑策略、收墩、结算、存档回放。
- `game.js`：牌桌渲染、交互、暂停调度、弹层与自动保存。
- `translations.js`：八国语言字典。
- `style.css`、`paper.svg`、`cover.svg`：响应式样式、纸纹与大厅封面。
- `engine.test.cjs`、`integration.test.cjs`：规则、存档、翻译与静态接入检查。

## 验证

在项目根目录运行：

```text
node --test games/hearts/engine.test.cjs games/hearts/integration.test.cjs
```

16 项检查通过，覆盖发牌与牌数守恒、四种换牌方向、非法操作不改变状态、首墩、跟花色、破心、收墩、射月、100 分阈值与并列胜利、合法存档回放及损坏存档、八国语言键与占位符、静态资源和唯一大厅登记。其中自动模拟 60 场完整对局，每一步检查牌数与计分，并定期比较回放状态。

通过本机静态服务器实玩完整 13 墩，确认本局四人得分合计 26、自动结算和下一局改为向右换牌；另实测换牌、提示、出牌、电脑回合、键盘快捷键、暂停保持牌面、恢复、刷新续局、上一墩回看、计分簿、说明弹层、取消重开及重新开局。大厅搜索「红心」只返回对应游戏，进入与返回均保留语言，重新进入保持第二局进度。控制台无脚本错误。

布局检查覆盖 320×568、360×640、390×844、568×320、844×390、768×1024、1024×768、1280×720、1920×1080。另以八种语言覆盖 320×568、360×640、568×320、844×390，共 32 组，页面没有横纵溢出，手牌及主要按钮在屏内。短横屏说明在弹层内部滚动，关闭、继续和返回入口可达。

未使用实体手机验证触摸、安全区或浏览器地址栏变化。`file://` 运行通过相对路径及无模块、无本地 fetch 依赖检查，未在浏览器内实测。射月、整场结束与并列胜利由规则测试验证。
