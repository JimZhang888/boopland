# 钢铁洪流

红白机《坦克大战》玩法启发的单人基地防守游戏，使用项目统一的纸张、铅笔线稿和低饱和配色。入口为 `index.html`，已在根目录 `gamelist.js` 登记。HTML、CSS、Canvas 和普通 JavaScript，无构建步骤、远程素材或新增依赖。

## 操作

- 方向键 / WASD：四向移动，炮口跟随车身转向。最小步长为半格（地图整格 48，半格 24 个逻辑像素），平滑走完一步后才能停稳或转弯；按住连续移动。
- 空格 / J：开火，可按住连发；支持自动开火开关。
- P / Esc：暂停与继续；打开手册、切出窗口或隐藏页面也会暂停。
- 手机：拖动四向摇杆移动，可与开火键同时操作。摇杆包含中心死区、斜向防抖和指针捕获，松手、取消触摸或切出窗口会回中。快速轻推也会走满半格；聚焦摇杆后仍可用方向键 / WASD，开火按钮支持键盘或辅助技术激活。
- 音效默认关闭，用户开启后才创建音频上下文。最高分保存在本地，存储不可用不影响游玩。

## 玩法

- 每关 20 辆敌军，初始 3 辆己方坦克。基地被敌军击中或坦克耗尽则结束。己方炮弹不会伤害基地。
- 5 张地图循环出现，后续关卡逐步提升敌军速度和同时出场数量；通过一关奖励 1000 分。
- 敌军分普通、快速、重装三种。重装需要命中 3 次。双方炮弹相碰会抵消。
- 砖墙可逐层破坏；钢墙需最高火力才能击破；河流阻挡坦克但不阻挡炮弹；树林提供视觉遮蔽。
- 标记敌军被击破后掉落补给：火力升级、12 秒护盾、9 秒敌军冻结、16 秒基地加固、清除当前敌军、增援坦克。
- 火力升级依次提供高速炮弹、双发、击破钢墙。中弹后升级归零；复活后有 3 秒护盾。
- 沿用全站八国语言；游戏内不设语言切换器，返回大厅保留语言参数，收到语言变化事件时不重置进度。

## 文件

- `engine.js`：与 DOM 无关的模拟、地图、碰撞及敌军行为。
- `game.js`：Canvas 绘制、输入、界面状态、音效及存储。
- `locales.js`：八国语言静态与动态文案。
- `style.css` / `cover.svg`：响应式布局与大厅封面。
- `engine.test.cjs` / `runtime.test.cjs`：模拟规则和真实输入处理、动画循环的自动化回归检查。
