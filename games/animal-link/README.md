# 动物连连看

纸质、铅笔手绘风格的经典连连看。入口为 `index.html`，已登记在根目录 `gamelist.js` 的「益智」分类。

原生 HTML / CSS / JavaScript，无构建、第三方运行时、CDN 或网络素材。可直接双击 HTML，也可通过普通静态服务器运行。动物线稿沿用本项目消消乐的图案，文件独立存放，不依赖其他游戏目录。

## 玩法

- 依次点击两张相同图案；水平、竖直连线最多转弯两次，不能穿过其他图案，可以从棋盘边缘绕行。
- 清空棋盘即通关，可继续下一页。轻松为 6×6（18 对），标准为 8×6（24 对），挑战为 8×8（32 对）。
- 动物和水果各有 8 种图案；轻松模式使用前 6 种。
- 提示标出可连的一对及路线；洗牌保留已经清空的位置。两项均不限次数，结算显示使用次数。
- 生成和洗牌会构造完整可解的消除顺序；实际游玩遇到无路可连时，自动免费洗牌。
- 不设倒计时。第一次选择、提示或洗牌开始计时；暂停、说明和确认弹层停止计时，切换到后台后需继续游玩才恢复。
- 难度和图案切换会先确认再开始新局。最快完成时间按难度、主题分别保存在本机，允许使用帮助；存储不可用时仍可正常游戏。
- 点击、触摸均可操作。棋盘支持方向键导航、Enter / 空格选择、Home / End 跳转、Esc 取消选择。音效默认关闭。
- 短横屏时标准棋盘自动转为 6 行 8 列，保持原来的图案、空位、选择和提示路线；旋转不会重开游戏。
- 使用项目公共八国语言设置，游戏内不提供语言切换，返回大厅保留语言。

## 扩展图案

在 `themes.js` 的 `LinkThemes` 中添加主题，或往现有主题的 `icons` 数组追加图案：

```js
{
  id: 'new-theme',
  label: 'newTheme',
  icons: [
    { id: 'new-icon', label: 'newIcon', wash: '#e6eadb', svg: '<svg viewBox="0 0 100 100" aria-hidden="true">...</svg>' }
    // 继续添加；推荐至少 8 种。
  ]
}
```

`id` 在同一主题中唯一且非空，`label` 对应 `translations.js` 的八语文案，`svg` 是项目内可信的静态图稿（也可在 SVG 内引用本目录的相对图片路径）。更大的图案池可调整 `game.js` 中 `modes` 的 `types`。主题选择器自动读取配置；`engine.js` 只处理图案 ID，不需要随主题修改。
