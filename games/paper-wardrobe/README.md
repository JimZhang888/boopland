# 纸间衣橱

入口：`index.html`。纯原生 HTML/CSS/JavaScript，无构建、CDN、数据 fetch 或第三方美术依赖。可从 `../../games.html` 的休闲分类进入。

## 内容与操作

- 73 件原创服饰、配饰和布景：初始开放 61 件，12 件通过首次完成主题或委托获得。包括 7 个发型、9 件上衣、8 件裙裤、7 条连衣裙、6 件外套、10 件鞋袜、16 件配饰、6 个背景和 4 张贴纸。
- 自由穿搭：点选试穿，连衣裙与上下装互斥；鞋袜、帽饰、颈饰、包袋和手持物分槽组合。可用灵感搭配、三种肤色、重置及最多 25 步撤销。
- 场景挑战：雨天书店、秋日野餐、冬夜音乐会、午后画廊、海边散步、星空野营。
- 小店委托：骑行、策展、花店茶会、图书馆、旧物集市、提琴手谢幕，均有明确颜色、风格和活动偏好。
- 收藏册可存 24 套并恢复；满册时仍可导出新搭配。PNG 明信片为 1040 × 1440 像素，包含完整造型、背景、装饰、标题和本机日期。导出弹窗提供下载链接和可长按保存的预览图。
- 触摸或鼠标点选；键盘 Tab 导航、Enter/空格激活、Esc 关闭弹窗。衣橱与长弹窗内部可滚动。主页面及弹窗内均有固定目的地的返回大厅链接。

## 搭配规则

评分满分 100，达到 75 分完成。场景按天气 40、风格 30、活动 30 分；委托将天气项改为颜色偏好 40 分。风格用两件以上呼应要求的服装或配饰即可拿满分；颜色以主服装为主。发型、肤色、背景、贴纸均不参与评分。

骑行活动项要求可骑行的裤装/衬衫裙、舒适鞋、双手空闲同时满足，避免只靠颜色和装饰通过。其他活动与天气有部分分数，反馈给出具体服饰调整建议。每项保留历史最高分，奖励不重复发放。

图层依次为：场景、阴影、雨伞背层、头发背层、身体、袜子、鞋、上衣、裙裤/连衣裙、外套、颈饰、包袋、头发前层、帽饰/手持物、手部、场景贴纸。长发自然覆盖肩部包带。衣服和人物使用同一 SVG 坐标系，缩略图复用原始单品线稿。

本轮已检查 73 张单品缩略图、12 组外套/发型/裙装/肤色叠穿、封面、完整明信片及 SVG 引用的唯一性，原有规则回归检查通过。浏览器预览因本机地址访问未获授权而停止，因此本轮没有新增浏览器实测结果。

## 本地数据与站点接入

`localStorage` 键：`boopland-paper-wardrobe-v1`，保存版本、当前穿搭、已解锁奖励、最高分、收藏册和当前玩法。读取时验证单品、槽位、解锁、分数和日期，损坏条目回退；存储不可用时继续游玩并提示导出。

共用 `../../i18n.js`，作用域 `wardrobe`，八种语言各 207 个键，覆盖界面、服饰、主题、动态点评和无障碍标签；语言变更不重置游戏。页面使用一次 `../../analytics.js`。大厅新增记录和七种其他语言卡片译文；没有修改公共语言、统计或其他游戏。
