# 黄金矿工

Boopland 的纸质手绘黄金矿工小游戏。入口为 `index.html`，已在根目录 `gamelist.js` 登记，分类为「休闲」。所有绘图由本地 Canvas / SVG 完成，没有外部资源、构建依赖或数据请求。

## 游玩

- 点击矿场或「放下钩子」，也可按 **空格 / ↓**，沿摆动方向出钩。
- 黄金价值 100 / 250 / 500，钻石 600，石头 20，惊喜袋 100 / 200 / 350。大金块与石头回收较慢。
- 挂着矿石回收时，点击炸药或按 **↑ / B**，消耗一支炸药丢弃矿石、快速收钩，不获得这块矿石的收益。
- 六关目标依次为 650、1050、1450、1800、2200、2650；时间为 60、60、65、65、70、75 秒。矿石拉回地面后计分，达标即过关。
- 关间使用钱袋金币补充炸药、升级卷扬机或购买下一关的 10 秒额外时间。卷扬机最多三级，每级额外增加基础回收速度的 30%；升级在本次旅途中永久生效。购物不扣总收获。
- **P / Esc** 暂停；切换标签、窗口失焦或离开页面自动暂停。说明弹窗关闭后恢复原先的暂停状态。
- 失败重试恢复本关开始时的钱袋、炸药、升级、追加时间及原矿石布局，不重复累计收益。通关后可以开始新旅程。
- 音效默认关闭，交互开启后才初始化音频。最高总收获和音效设置存于本机；存储不可用时仍可游玩。

## 集成

直接打开本游戏 `index.html`，或从根目录 `games.html` 搜索「黄金矿工」进入。也可用任意静态服务器运行，支持子目录部署。使用全站 `../../i18n.js` 的八国语言，包含动态文案、无障碍标签和大厅卡片；返回大厅携带语言参数。没有游戏内语言选择器。

`engine.js` 为独立游戏逻辑，`scene.js` 绘制场景，`game.js` 处理界面与输入，`translations.js` 提供翻译。Canvas 按设计区域完整容纳，按设备像素比绘制（上限 2）；窗口变化保留游戏状态。装饰反馈遵循减少动态效果设置。

## 验证

在项目根目录运行：

```text
node --test games/gold-miner/engine.test.cjs
```

自动检查覆盖：600 个矿场布局的边界、可达性与不重叠；扫掠碰撞；出钩防重复；只在回收后计分；负重与升级速度；炸药；暂停与异常帧时长；超时失败；商店限制；重试回滚；矿石耗尽；六关完整流程；八国语言键与占位符一致；清单及本地资源路径。

浏览器布局检查覆盖 320×568、360×640、390×844、568×320、844×390、768×1024、1024×768、1280×720、1920×1080。检查了主要按钮可见、点击区域和页面无溢出，并检查八国语言在 320×568 的开始界面。浏览器键盘与点击试玩覆盖放钩、回收计分、暂停、说明弹窗及超时结算。模拟视口不等同于实体触屏设备测试。

已通过静态 HTTP 服务器实测大厅搜索、进入游戏、返回大厅及语言参数保留。内置浏览器的安全策略不允许 `file://` 协议，因此直接双击运行方式仅完成了相对路径、普通脚本加载、无 `fetch` / 外部依赖等静态检查，未作浏览器实测。关间购物和完整六关通关由自动化逻辑测试覆盖，尚未逐关人工通关。
