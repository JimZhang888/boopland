# 骰隐江湖

原生 HTML / CSS / JavaScript 的回合制骰子武侠小游戏。入口 `index.html`，在大厅 `gamelist.js` 的「策略」分类登记。采用纸张底色、原创 SVG 山水与侠客、低饱和配色，不需要后端、安装依赖或构建。

## 玩法

- 六场比武：竹林、溪桥、古寺、雪岭、云台，最后挑战青山掌门。初始生命 38，敌人生命依次为 23、30、37、44、52、66。
- 每回合掷四枚六面骰，点击骰子后选择出招、格挡或调息。可把多枚骰子放入同一招式；点击已放入的骰子可取回。全部分配后才可出手。
- 每回合可重掷一枚尚未分配的骰子一次，刷新不会恢复次数或改变骰序。
- 出招伤害、格挡护盾、调息回血的基础值均为对应骰子之和。调息先结算，随后玩家出招，敌人存活才反击；护盾只在当前回合有效。敌人守势会减少玩家伤害。
- 敌人的下一招始终公开，并在每经过四回合后增加 2 攻击。出手前可看伤敌、受伤、回血预览。
- 连招可叠加，各种每回合最多触发一次：
  - **寸劲**：出招有至少两枚 1–2 点，伤害 +7。
  - **借力**：格挡包含 1 和 2，护盾 +6；完全抵消来袭且敌人存活时，反击 4 点。
  - **归元**：调息有一对相同的 1、2 或 3，回血 +5。
  - **三才**：已使用的骰子包含 1、2、3（可分布在不同招式），攻击 +3、护盾 +3、回血 +2。
- 每胜一场可选一部可叠加的心法：磨剑（有攻击骰时伤害 +2，回血 9）、铁衣（有格挡骰时护盾 +2，回血 9）、养气（生命上限 +6，有调息骰时回血 +1，立即回血 14）。第六场胜利直接结算。
- 声望 = 过关数 ×120 + 连招触发数 ×8 + 剩余生命 ×3 − 总出手数 ×2；通关额外 +300，最低为 0。

## 操作与存档

鼠标和触屏采用相同点击流程。键盘 `1–4` 选骰或取回，`A / D / H` 分别分配出招、格挡、调息，`R` 掷骰或重掷，空格在出手按钮聚焦时执行，`Esc` 关闭说明或取消重开。

游戏为纯回合制，无倒计时或持续游戏循环。帮助与重开确认使用原生 dialog；恢复游戏不需要额外暂停处理。离开标签页会停止短暂的视觉效果。

本局与随机数状态保存在 `boopland-dice-jianghu-v1`，最佳声望保存在 `boopland-dice-jianghu-best`。每次操作保存；存储受限时仍可玩，损坏的存档会开启新局。重开保留最佳成绩。

使用根目录 `i18n.js` 的八国语言和语言传递规则。没有独立语言选择器；返回大厅保留 `lang`。所有资源使用相对路径和普通脚本，既可从静态服务器访问，也按项目约定支持直接打开。

## 文件

- `engine.js`：确定性骰序、分配、连招、伤害预览、结算、升级、存档校验。
- `game.js`：DOM 交互、键盘、自动存档、说明与结算弹窗。
- `translations.js`：八种语言，各 89 个键。
- `style.css`、`index.html`：响应式一屏布局与原创山水侠客 SVG。
- `cover.svg`：大厅原创封面。
