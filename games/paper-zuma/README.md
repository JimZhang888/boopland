# 纸间祖玛 / Paper Zuma

纸张与铅笔手绘风格的祖玛小游戏。已登记在根目录 `gamelist.js`，附独立 SVG 封面和八国语言卡片。无需构建、安装依赖或后端；从大厅进入，或直接打开本目录的 `index.html`。

## 操作与玩法

- 鼠标移动瞄准、左键发射；触屏按住拖动瞄准、松手发射。左右方向键 / A、D 转向，Enter 发射。
- 点击彩珠按钮、按空格或鼠标右键交换当前与下一颗彩珠。每种颜色有独立图案，弹药从仍在场上的颜色中选择。
- 相邻同色达到三颗即可消除，每颗 10 分。断链会回吸，重新接上的同色可触发连锁，得分乘以连锁倍率。
- 每消除 12 颗充满减速技能，点击「慢一点点」或按 F，将前进速度降低到 30%，持续 7 秒。
- 共六关、三种轨道方向，后续关卡增加彩珠数量、速度和第五种颜色。清空所有彩珠（包括尚未进入画面的彩珠）过关；过关奖励为关卡序号 × 100 分。
- 彩珠到达树洞时失败，可重试本关，保留此前关卡得分。暂停面板也提供重玩本关；六关全部完成后可以重新挑战。
- P / Esc 或暂停按钮暂停。切换标签页、窗口失焦时自动暂停，回来后手动继续。
- 右上角可开启音效。最高分和声音偏好保存在本机浏览器；存储被禁用时仍可游玩。

## 文件

- `engine.js`：等弧长轨道采样、固定时间步长、扫掠碰撞、插珠、回吸连锁和关卡状态机；可直接由 Node 测试。
- `game.js`：Canvas 手绘场景、输入、界面、程序音效和本地存储。
- `style.css`：一屏布局，画布等比容纳可用区域，兼顾小竖屏与短横屏。
- `translations.js`：接入全站 `BooplandI18n` 的八国语言，共 71 个键。游戏内不添加语言切换入口，返回链接保留语言参数。
- `cover.svg`：独立本地封面，无外部素材依赖。
