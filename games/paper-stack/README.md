# 叠叠高

纸张质感的等距叠塔小游戏。方块交替沿两个方向滑动，点按后保留与塔顶重合的部分，突出边缘切落；完全落空时结束。高度每次成功叠放加一，速度逐渐上升并有上限。

## 操作与规则

- 点击画面、下方按钮，或按空格 / Enter：开始、落块、继续或再来一局。
- P / Esc 或右上角暂停：暂停 / 继续；暂停时可以重新开始。
- 完美叠放自动对齐，不削减方块。连续三次完美叠放，两条边各补回 10 个逻辑单位，最多回到初始尺寸。窄方块的完美容差会同步缩小。
- “?” 打开说明。音效默认关闭，可手动开启，设置与最高高度保存在本浏览器；存储不可用时仍可游玩。
- 切换标签页自动暂停，回来后手动继续。调整窗口和切换全站语言不重置本局。
- 沿用全站八国语言；语言入口仅在欢迎页。返回大厅链接保留语言。

## 运行

从 `games.html` 搜索“叠叠高”进入，或直接打开本目录的 `index.html`。原生 HTML / CSS / JavaScript，不依赖构建、后端、CDN、fetch 或 ES 模块。封面为本目录独立 SVG。

在项目根目录运行检查：

```powershell
node --test games/paper-stack/engine.test.cjs games/paper-stack/runtime.test.cjs
```

- 内置浏览器实测：开始、键盘落块计分、失败结算、暂停 / 继续、重开、说明开关、音效开关状态、刷新保留纪录、大厅搜索与往返、链接保留语言。
