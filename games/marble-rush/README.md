# 弹珠派对 / Marble Party

纸质手绘风格的弹珠打砖块游戏。已登记在根目录 `gamelist.js`，无需安装依赖、构建或后端。双击本目录 `index.html`，或从小游戏大厅进入即可。

## 玩法

- 鼠标移动 / 手指拖动瞄准，松手连续发射；键盘左右方向键瞄准、空格发射。
- 首发 30 颗弹珠，击中 `+5` 增加下一轮的弹珠数量，每轮再增加 2 颗，最多 120 颗。
- 击碎带星形标记的炸弹，对周围砖块造成范围伤害，能引发连锁爆炸。
- 击碎砖块和收集弹珠积攒能量；满格时点「穿透齐射」或按 F，下一轮弹珠获得三倍伤害和穿透效果。再次点击可取消准备，实际发射才消耗能量。
- 所有弹珠返回后进入下一波。砖块逐波下移，触及底线时结束。
- P / 暂停按钮暂停；暂停面板可重新开始。切换标签页或窗口失焦会自动暂停。
- `1× / 2×` 切换速度；发射两秒后可以收回剩余弹珠。单颗弹珠最长飞行 20 秒，避免卡局。
- 提供音效开关；最高分和音效偏好保存到本机浏览器。存储不可用时仍可游玩。

## 文件

- `engine.js`：固定步长物理、碰撞、连锁、波次及状态机。普通脚本，兼容本地文件打开。
- `game.js`：画布、粒子、程序生成音效、输入与界面。
- `translations.js`：八国语言，接入全站 `BooplandI18n`，游戏内无单独语言选择器。
- `cover.svg`：本地矢量手绘封面。
