# 小小流水线

在纸质工作台上安排传送带、切割机、染色机与旋转机，自动生产符合样品的物品。玩法参考 [shapez](https://store.steampowered.com/app/1318690/shapez/) 的形状加工与自动化生产，自行实现工作台、关卡、图形和交互。

入口为 `index.html`，大厅已通过 `gamelist.js` 登记为「策略」游戏。纯原生 HTML/CSS/JavaScript，普通相对路径脚本，无构建、安装依赖、远程字体或素材请求。支持本地文件与静态服务器。使用全站 `i18n.js` 八国语言和 `analytics.js`。

## 游玩

- 8 张订单，共 96 件成品。逐步解锁染色、切割与形状旋转，完成后可重玩。
- 点击放置，拖动连续铺设；传送带随拖动方向转弯，快速拖动会补齐经过的格子。右键或橡皮擦拆除设备。
- R 改变设备出货方向，1–5 选择工具，空格暂停或继续，Ctrl/⌘+Z 撤销。工作台获得焦点后，方向键移动光标，Enter 放置，Delete / Backspace 擦除。
- 手机可以使用屏幕上的工具、方向、颜色、撤销、速度和开工按钮。长竖屏把整个工作台转为纵向布局，保留物品朝向和进度。
- 原料口自动生产圆形、方形；设备从侧面或后方接货，沿箭头输出。每格最多一个物品，堵塞会停止上游运输。
- 染色机有四种颜色；切割机把整块切成右半，再切成右上四分之一；旋转机把物品顺时针旋转 90°。旋转设备出货方向不改变物品本身的朝向。
- 订单要求形状、颜色、朝向完全一致。错误成品会回收，没有费用或倒计时。
- 提供可开关的参考路线、帮助弹窗、订单手册、1×/2×/3×速度。订单间保留设备，清空在途物品。
- 在本机自动保存工作台与订单进度；恢复时暂停生产，重新生成在途物品。切换标签页自动暂停。存储不可用时仍能游玩。

## 文件

- `engine.js`：独立生产模拟、加工规则、订单、存档校验和参考路线；可以在 Node 中直接测试。
- `art.js`：Canvas 工作台与手绘 SVG 图标。
- `game.js`：指针/键盘输入、界面、弹窗、持久化与页面生命周期。
- `translations.js`：完整八国语言静态与动态文案。
- `cover.svg`：独立手绘大厅封面。

## 验证

运行 `node games/tiny-factory/verify.cjs`。10 组检查覆盖全部订单顺序通关、96 件交付、加工与朝向、错误成品、堵塞与恢复、合流冲突、固定设备与解锁、存档恢复和异常数据、八国语言、清单登记与资源路径。

浏览器验收已通过：从大厅搜索进入、返回大厅、语言参数保留、拖动铺设与转弯、键盘放置、撤销、暂停和倍速、前三张订单实际通关（包括染色与切割）、解锁设备、刷新恢复、重开确认和取消、帮助弹窗。游戏控制台无错误。验收产生的进度已通过游戏内重开恢复为第一张订单。

实测视口：320×568、360×640、390×844、568×320、844×390、768×1024、1024×768、1280×720、1920×1080，页面无横纵溢出，主要控件没有超出视口。八国语言分别检查了 320×568 和 568×320，长文字按钮没有横向溢出。320×568 下帮助内容在弹窗内部滚动。390×844 下纵向工作台已视觉检查。

尚未实测实体触摸设备，以及浏览器 `file://` 双击模式；已检查 Pointer Events 输入、相对资源路径和非模块普通脚本的兼容性。大厅字体子集已补全新增文案中原字体支持的字符，并更新缓存版本。
