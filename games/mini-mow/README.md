# 迷你割草

原生 HTML、CSS、JavaScript 的三分钟生存小游戏。入口为 `index.html`，已登记到大厅；无构建依赖、远程素材或后端，沿用全站八国语言设置与纸质铅笔画风。

## 操作与玩法

- WASD / 方向键移动；手机或鼠标按住草地，拖动虚拟摇杆移动。
- 自动向附近怪物发射种子；飞叶绕身攻击。收集绿色经验石，升级时从三项随机强化中选择一项，升级同时恢复 5 点生命。
- 八种强化：伤害、攻速、飞叶数量、种子数量、范围冲击波、吸取范围、移速、生命补给。红色果实恢复生命。
- 空格或右下按钮冲刺，短暂无敌，冷却 4 秒。受到接触伤害后也有短暂保护。
- 共六波，每 30 秒增强；第 150 秒出现荆棘王。存活至 180 秒即通关，击败荆棘王会掉落大量经验和治疗果实。
- P / Esc 或顶部按钮暂停。离开窗口或切换标签页会自动暂停；恢复后需主动继续。
- 音效默认关闭，可在顶部开启。本地保存最佳生存时间、最多击退数和音效偏好；存储不可用仍可游玩。

## 文件

- `engine.js`：可独立运行的战斗、成长和状态机。
- `game.js`：Canvas 绘制、键盘 / 指针输入、界面、音效与记录。
- `translations.js`：八种语言的 60 项静态 / 动态文案。
- `style.css`、`cover.svg`：一屏布局与手绘封面。

## 验证

运行 `node --test games/mini-mow/engine.test.cjs`。12 项测试通过，覆盖移动与边界、暂停及重开、冲刺及冷却、受伤保护和失败、自动攻击、飞叶和范围伤害、连续升级及经验溢出、八种强化、Boss 与通关、掉落数量上限、四个随机种子的完整三分钟模拟，以及翻译、相对资源路径和大厅登记。完整模拟为验证状态与资源边界提高了测试角色生命值，不代表真人难度测试。

浏览器实测了开始、键盘输入、空格冲刺、指针拖动、暂停继续、帮助、升级选择、胜负结算和重开，以及大厅搜索、进入、返回并保留语言。升级与结算使用临时测试场景触发，场景文件已移除，测试记录与正式记录隔离。未发现脚本错误。

布局尺寸检查覆盖 320×568、360×640、390×844、568×320、844×390、768×1024、1024×768、1280×720、1920×1080；页面无横纵向溢出。八种语言检查了小竖屏及短横屏升级布局，短横屏已精简装饰，三项选择完整可达。说明弹层允许内部滚动。

视觉截图主要在内置浏览器的默认窄视口完成；大视口检查基于实际浏览器布局尺寸，截图能力受当前面板宽度限制。触摸路径通过指针拖动模拟，未做实体手机测试。直接双击模式做了相对路径与普通脚本检查，未做 `file://` 浏览器实测。未提交或发布。
