本项目的网页版本：
huiwen-mincho-welcome.woff2 提取 index.html 欢迎页所需字符。
huiwen-mincho-lobby.woff2 提取 games.html、games-i18n.js、gamelist.js、
i18n.js 中的大厅界面、游戏名称、简介、分类和动态提示所需字符。
两份文件均由上述原始字体转换为 WOFF2；未修改字形轮廓，
保留原字体名称和版权元数据。包含各页面八种语言文案中原字体
支持的字符和可用的拉丁字符。
原字体没有收录的字符（例如韩文）由 CSS 中的系统字体回退显示。
欢迎页和大厅各自引入对应子集，与网站一起部署，不依赖第三方字体服务。

更新页面文案或游戏清单后，如添加了当前子集未包含的字符，使用原版 TTF
重新生成子集。以下命令在项目根目录执行，需要开发工具 fonttools
及 Brotli；网站运行和部署本身没有 Python 或构建依赖：

python -m fontTools.subset "原版字体路径.ttf" --text-file=index.html --unicodes=U+0020-017F --flavor=woff2 --name-IDs=* --name-legacy --name-languages=* --output-file=assets/fonts/huiwen-mincho-welcome.woff2

大厅子集（先在 PowerShell 合并大厅的四份文本到临时文件）：

Get-Content -Raw -Encoding utf8 games.html,games-i18n.js,gamelist.js,i18n.js | Set-Content -Encoding utf8 "$env:TEMP/boopland-lobby-font-text.txt"
python -m fontTools.subset "原版字体路径.ttf" --text-file="$env:TEMP/boopland-lobby-font-text.txt" --unicodes=U+0020-017F --flavor=woff2 --name-IDs=* --name-legacy --name-languages=* --output-file=assets/fonts/huiwen-mincho-lobby.woff2
